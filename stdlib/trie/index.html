Standard Library

trie — Compressed radix tree (Patricia trie)

Module trie (lib/trie.lora) exports 18 declarations. Import with use trie;.

Overview

trie implements a compressed radix tree (Patricia trie) for byte-slice and UTF-8 string keys.

Edges store compressed byte labels, and each node keeps its children sorted by their first byte. This makes exact lookups (get / get_str), longest-prefix routing (longest_prefix / longest_prefix_str), and lexicographical prefix enumeration (keys_with_prefix / keys_with_prefix_str) fast and compact.

SymbolPurpose
new / size / clearCreate an empty radix tree, query key count, or reset
put / put_strInsert or overwrite a byte or string key-value pair
get / get_str / contains / contains_strBorrowed value lookup and membership check
remove / remove_strDelete a key and prune dead leaf nodes
longest_prefix / longest_prefix_strReturn owned prefix_match (key: ^str, value: ^[]u8)
keys_with_prefix / keys_with_prefix_strReturn owned ^[]^str in lexicographical order

Valid Usage & Examples

Longest-prefix HTTP route matching

Store route prefixes and resolve the most specific match with trie::longest_prefix_str.

lora Allowed 
use strings;
use trie;

export fn main() void = {
	let routes = trie::new()!;
	trie::put_str(&routes, "/", "root")!;
	trie::put_str(&routes, "/api/v1", "v1")!;
	trie::put_str(&routes, "/api/v1/users", "users")!;

	match (trie::longest_prefix_str(&routes, "/api/v1/users/42")!) {
		void => assert(false),
		let m: trie::prefix_match => {
			assert(m.key == "/api/v1/users");
			assert(strings::from_bytes(m.value) == "users");
		},
	}
}

Lexicographical prefix autocomplete

Enumerate all stored keys sharing a prefix using trie::keys_with_prefix_str.

lora Allowed 
use trie;

export fn main() void = {
	let t = trie::new()!;
	trie::put_str(&t, "romulus", "3")!;
	trie::put_str(&t, "romane", "1")!;
	trie::put_str(&t, "romanus", "2")!;
	trie::put_str(&t, "ruber", "4")!;

	let matches = trie::keys_with_prefix_str(&t, "rom")!;
	assert(len(matches) == 3z);
	assert(matches[0] == "romane");
	assert(matches[1] == "romanus");
	assert(matches[2] == "romulus");
}

Disallowed Forms & Diagnostics

Ignoring the nomem union on trie::new or trie::put_str

trie::new, put, longest_prefix, and keys_with_prefix all return error unions with nomem and must be handled.

Type Error: cannot assign (trie | nomem) to trie without unwrapping or propagating nomem
lora Rejected 
use trie;

export fn main() void = {
	let t: trie::trie = trie::new(); // error: unhandled nomem
	trie::put_str(&t, "k", "v"); // error: unhandled nomem
}
lora Allowed 
use trie;

export fn main() (void | nomem) = {
	let t = trie::new()?; // ok: propagate nomem with ?
	trie::put_str(&t, "k", "v")?; // ok: propagate nomem with ?
}

Constraints & Limits

Lookup / Insert
O(len(key))
Children are kept sorted by first byte for deterministic prefix order.
Owned returns
prefix_match / ^[]^str
`longest_prefix*` and `keys_with_prefix*` allocate owned copies; `get*` returns borrowed views.
Node arena
Arena-indexed
Internal nodes live in `t.nodes`; `remove` detaches dead leaves and `clear` resets the arena.
