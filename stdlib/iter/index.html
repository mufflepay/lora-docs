Standard Library

iter — composable lazy iterators

Module iter (lib/iter.lora) exports 41 declarations. Import with use iter;.

Overview

Composable lazy iterator sources, adaptors, and consumers built around the iter::source[T] interface.

Because adaptors wrap source[T] interface pointers (&src), pipelines execute lazily element-by-element without intermediate allocations until a consumer (collect, collect_in, fold, sum_i64, find, etc.) drives the chain.

Interfacesource[T] (fn next() (T | done))

Valid Usage & Examples

Composing a lazy filter-map-skip-take pipeline

Chain range, filter, map_over, skip, and take and reduce with sum_i64 in zero heap allocations.

lora Allowed 
use iter;

fn is_even(x: *const i64) bool = (*x % 2) == 0;
fn square(x: *const i64) i64 = *x * *x;

export fn main() void = {
	let r = iter::range(1, 11);
	let f = iter::filter::[i64](&r, &is_even);
	let m = iter::map_over::[i64, i64](&f, &square);
	let sk = iter::skip::[i64](&m, 1z);
	let tk = iter::take::[i64](&sk, 3z);
	assert(iter::sum_i64(&tk) == 116);
}

Collecting into owned slices or expanse regions

Materialize an iterator into a heap-allocated ^[]T with collect or into a region with collect_in.

lora Allowed 
use expanse;
use iter;

export fn main() (void | expanse::full | expanse::uncommitted | nomem) = {
	let xs: [3]i64 = [10, 20, 30];
	let rev = iter::rev_slice(xs[..]);
	let col = iter::collect::[i64](&rev)?;
	defer free(col);
	assert(col[0] == 30 && col[2] == 10);

	let reg = expanse::auto();
	defer expanse::finish(&reg);
	let r = iter::range(5, 8);
	let rc = iter::collect_in::[i64](&reg, &r)?;
	assert(len(rc) == 3z && rc[0] == 5 && rc[2] == 7);
}

Disallowed Forms & Diagnostics

Creating a zero-step range or zero-step step_by iterator

iter::range requires step != 0 and iter::step_by requires step > 0.

CONTRACT: requires(step != 0) failed in iter::range
lora Rejected 
use iter;

export fn main() void = {
	let _ = iter::range(0, 10, 0); // error: step 0 violates requires(step != 0)
}
lora Allowed 
use iter;

export fn main() void = {
	let r = iter::range(0, 10, 2); // ok: non-zero step
	assert(iter::count::[i64](&r) == 5z);
}

Constraints & Limits

Single-pass
Stateful iterators
Iterators mutate in place on `.next()`; create a fresh source to iterate again.
Overflow safety
Clamped step / *%=
`range_iter` guards against `i64` overflow near `i64::MAX`/`MIN`; `product_i64` uses wrapping `*%=`.
collect_in
Temporary heap buffer
`collect_in` calls `collect` first and frees the temporary slice before returning the region slice.
