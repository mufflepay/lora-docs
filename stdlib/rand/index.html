Standard Library

rand — random numbers

Module rand (lib/rand.lora) exports 28 declarations. Import with use rand;.

Overview

rand provides fast, deterministic pseudo-random number generators (pcg and chacha8) implementing the source interface (fn draw() u64), a thread-local global() chacha8 seeded from OS randomness, and unbiased range/distribution helpers.

Security note: rand is for simulations, sampling, tests, and games — use crypto::random for cryptographic keys, tokens, or secrets.

Valid Usage & Examples

Deterministic simulation with `pcg`, `i64_between`, and `shuffle_slice`

Seed a pcg generator for reproducible dice rolls, normal deviates, and in-place slice shuffling.

lora Allowed 
use rand;

export fn main() void = {
	let r = rand::new_pcg(1u64, 2u64);
	let die = rand::int_n(&r, 6) + 1;
	assert(die >= 1 && die <= 6);

	let temp = rand::i64_between(&r, -10i64, 10i64);
	assert(temp >= -10i64 && temp <= 10i64);

	let deck: [5]int = [1, 2, 3, 4, 5];
	rand::shuffle_slice(&r, deck[..]);
}

Thread-local `global()`, `chacha8`, and Zipf distribution

Use rand::global() for quick unseeded draws and new_zipf for power-law sampling.

lora Allowed 
use rand;

export fn main() void = {
	let coin = rand::next_f64(rand::global()) < 0.5;
	let _ = coin;

	let z = rand::new_zipf(1.5, 1.0, 100u64) as rand::zipf;
	let seed: [32]u8 = [0x42u8...];
	let c = rand::new_chacha8(seed);
	let sample = rand::next_zipf(&z, &c);
	assert(sample <= 100u64);
}

Disallowed Forms & Diagnostics

Passing `n <= 0` to `int_n` / `u64_n` or `lo > hi` to `i64_between`

Bounded integer draws abort at runtime if n <= 0 or lo > hi.

RUNTIME ABORT: rand::int_n: n must be positive
lora Rejected 
use rand;

export fn main() void = {
	let r = rand::new_pcg(1u64, 2u64);
	let x = rand::int_n(&r, 0); // error: n <= 0 aborts at runtime
}
lora Allowed 
use rand;

export fn main() void = {
	let r = rand::new_pcg(1u64, 2u64);
	let x = rand::int_n(&r, 1); // ok: n > 0 satisfies precondition
	assert(x == 0);
}

Constraints & Limits

Non-Cryptographic
PCG / ChaCha8
Not reseeded or side-channel hardened for secrets; use `crypto::random` for keys/tokens.
Range Preconditions
n > 0, lo <= hi
`u64_n`, `i64_n`, `int_n`, and `i64_between` abort on invalid bounds.
Zipf Parameters
q > 1.0, v >= 1.0
`new_zipf` returns `void` if `q <= 1.0` or `v < 1.0`.

Module Guide & Examples

Random numbers for simulations, sampling, tests and games: not for keys, tokens or anything an attacker must not guess, which crypto::random is for.

A source makes 64 random bits at a time: pcg, small and fast, or chacha8, made from a stream cipher. Seeded alike, each makes the same numbers every time, on every system. global() is this thread's own chacha8, seeded from the system's randomness when first used. The functions here take any source, and make what is wanted of its bits: numbers in a range without bias, floats, normal and exponential deviates, permutations and shuffles.

let r = rand::new_pcg(1, 2); let die = rand::int_n(&r, 6) + 1; let coin = rand::next_f64(rand::global()) < 0.5;

lora 
use rand;

export fn main() void = {
	let r = rand::new_pcg(1, 2);              // the same numbers every run
	let die = rand::int_n(&r, 6) + 1;
	assert(die >= 1 && die <= 6);
	let coin = rand::next_f64(rand::global()) < 0.5;
	let order = rand::perm(&r, 10)!;
	assert(len(order) == 10);
}

Use these for simulations, sampling, tests and games. Anything an attacker must not guess, such as keys or tokens, needs crypto::random.

A source seeded the same way gives the same numbers on every system:

  • pcg is a 128-bit permuted congruential generator with the DXSM output function;
  • chacha8 is the ChaCha stream cipher with 8 rounds, its key the seed.

global() is the calling thread's own chacha8, seeded from the system the first time it's used. Ranges are drawn without modulo bias, and floats are spread evenly over every representable value they can take.
