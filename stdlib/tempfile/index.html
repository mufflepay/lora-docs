Standard Library

tempfile — Secure temporary files, directories, and atomic writes

Module tempfile (lib/tempfile.lora) exports 18 declarations. Import with use tempfile;.

Overview

tempfile wraps fs temporary files and directories with automatic cleanup on drop (impl drop for temp_file and impl drop for temp_dir), explicit persistence (persist, keep, keep_dir), and atomic file replacement (write_atomic).

SymbolKindPurpose
temp_file, new_file, new_file_instruct / fn0o600 temp file auto-unlinked on drop unless kept/persisted
file_path, file_handle, write_all, read_all, syncfnPath access, *fs::file handle, and I/O helpers
keep, close_and_remove, persistfnRetain, explicitly unlink, or sync+rename atomically
temp_dir, new_dir, new_dir_in, dir_path, child_path, keep_dirstruct / fn0o700 temp directory auto-removed recursively on drop
write_atomicfnWrite to sibling temp file, sync, chmod, and rename into place

Valid Usage & Examples

Scoped temporary directory and atomic persist

Create a temp_dir and temp_file that clean up automatically, or persist a temp file to its final destination.

lora Allowed 
use fmt;
use strings;
use tempfile;

export fn main() void = {
	let dir = tempfile::new_dir("work-*")!;
	let dest = tempfile::child_path(&dir, "out.txt")!;
	defer free(dest);

	let tf = tempfile::new_file_in(tempfile::dir_path(&dir), "stage-*")!;
	tempfile::write_all(&tf, strings::to_bytes("atomic data\n"))!;
	tempfile::persist(&tf, dest)!;
	fmt::printfn("persisted to {}", dest)!;
}

One-shot atomic file write

Use tempfile::write_atomic to safely replace a target file with explicit permissions.

lora Allowed 
use strings;
use tempfile;

export fn main() void = {
	let dir = tempfile::new_dir("atom-*")!;
	let target = tempfile::child_path(&dir, "state.json")!;
	defer free(target);
	tempfile::write_atomic(target, strings::to_bytes("{\"ok\":true}\n"), 0o640)!;
}

Disallowed Forms & Diagnostics

Using "/" inside a tempfile pattern

new_file_in and new_dir_in reject patterns containing / with rt::EINVAL.

Runtime: cannot create sub/tmp-*: Invalid argument (EINVAL, errno 22)
lora Rejected 
use tempfile;

export fn bad() void = {
	let _ = tempfile::new_file("sub/tmp-*")!; // error: '/' in pattern fails with EINVAL
}
lora Allowed 
use tempfile;

export fn good() (tempfile::temp_file | fs::error | nomem) = {
	return tempfile::new_file("tmp-*"); // ok: filename-only pattern without '/'
}

Constraints & Limits

Default patterns
"tmp-*" / "tmpdir-*"
Used by `new_file` and `new_dir` when no pattern is supplied.
Drop behavior
Unlink / remove_all
Drops remove the temp file/dir unless `keep`, `persist`, or `keep_dir` was called.
