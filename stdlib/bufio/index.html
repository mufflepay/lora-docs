Standard Library

bufio — buffered readers, writers and scanners

Module bufio (lib/bufio.lora) exports 35 declarations. Import with use bufio;.

Overview

bufio provides zero-allocation buffered reading, writing, and token scanning over any io::reader or io::writer. Callers supply the backing []u8 slice (on the stack or heap), and line/token slices returned by read_line, read_slice, peek, take, and scan are zero-copy views into that buffer valid until the next read.

Valid Usage & Examples

Scanning lines and words with a stack buffer

Use bufio::new_scanner with bufio::lines (default) or bufio::words without heap allocation.

lora Allowed 
use bufio;
use fmt;
use io;

export fn main() void = {
	let src = io::new_str_reader("alpha beta\ngamma\n");
	let buf: [256]u8 = [0...];
	let sc = bufio::new_scanner(&src, buf[..], &bufio::words);
	for (true) match (bufio::scan(&sc)!) {
		done => break,
		let tok: str => fmt::printfn("word: {}", tok)!,
	}
}

Peek, read_rune, and unread_rune

Inspect upcoming bytes with bufio::peek and push back a rune with bufio::unread_rune.

lora Allowed 
use bufio;
use fmt;
use io;

export fn main() void = {
	let src = io::new_str_reader("λabc");
	let buf: [64]u8 = [0...];
	let r = bufio::new_reader(&src, buf[..]);

	let head = bufio::peek(&r, 2)!;
	fmt::printfn("peeked {} bytes", len(head))!;
	let (ch, width) = bufio::read_rune(&r)! as (rune, usize);
	bufio::unread_rune(&r);
	let (ch2, _) = bufio::read_rune(&r)! as (rune, usize);
	fmt::printfn("rune={} width={}", ch2, width)!;
}

Buffered writing with explicit flush

Batch small writes in a stack buffer and flush to the underlying io::writer.

lora Allowed 
use bufio;
use fmt;
use io;

export fn main() void = {
	let out = io::new_buffer();
	let wbuf: [128]u8 = [0...];
	let w = bufio::new_writer(&out, wbuf[..]);
	bufio::write_str(&w, "key=")!;
	bufio::write_rune(&w, '✓')!;
	bufio::write_byte(&w, '\n')!;
	bufio::flush(&w)!;
	fmt::print(io::str_of(&out))!;
}

Disallowed Forms & Diagnostics

Passing an empty buffer to bufio::new_reader or bufio::new_scanner

All bufio constructors enforce requires(len(buf) > 0) at runtime.

Contract: bufio::new_reader: the buffer is empty
lora Rejected 
use bufio;
use io;

export fn bad() void = {
	let src = io::new_str_reader("data");
	let empty: [0]u8 = [];
	let r = bufio::new_reader(&src, empty[..]); // error: empty buffer violates requires(len(buf) > 0)
	let _ = bufio::read_byte(&r);
}
lora Allowed 
use bufio;
use io;

export fn good() void = {
	let src = io::new_str_reader("data");
	let buf: [64]u8 = [0...]; // ok: non-empty backing buffer
	let r = bufio::new_reader(&src, buf[..]);
	let _ = bufio::read_byte(&r)!;
}

Constraints & Limits

Max line / token length
len(buf)
`read_slice`, `read_line`, `peek`, `take`, `reserve`, and `scan` return `io::too_large` if an item exceeds `len(buf)`.
Unbounded line reading
append_until(..., limit)
Use `bufio::append_until` with a `u64` limit to read lines longer than `len(buf)`.
write_vec batch
16 iovec slices
`writer.write_vec` combines buffered data plus up to 15 caller slices per `dst.write_vec` call.
Pushback depth
1 byte / 1 rune
`unread_byte` and `unread_rune` only undo the immediately preceding call.

Module Guide & Examples

Buffered reading and writing, over any io::reader or io::writer.

A reader reads from its source in large pieces and gives them out a little at a time: by bytes, runes, lines or up to a delimiter, with a look ahead that consumes nothing. A writer gathers small writes and passes them on in large ones; flush passes on the rest. A scanner splits input into tokens: lines, words, runes, bytes, or by a function of the caller's.

Each takes a buffer of the caller's, on the stack or the heap, and allocates nothing. A line or token is a view into it, valid until the next read; one longer than the buffer is io::too_large, never cut.

Over any io::reader or io::writer, in a buffer of the caller's, with nothing allocated. A line or token is a view into the buffer, valid until the next read; one longer than the buffer is io::too_large, never cut.

lora 
use bufio;
use io;

export fn main() void = {
	let src = io::new_str_reader("alpha beta\ngamma\n");
	let buf: [64]u8 = [0...];
	let s = bufio::new_scanner(&src, buf[..], &bufio::words);
	let n = 0;
	for (true) match (bufio::scan(&s)!) {
		done => break,
		str => n += 1,
	}
	assert(n == 3);
}
