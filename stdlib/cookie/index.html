cookie — RFC 6265 cookies and cookie jar

Module cookie (lib/cookie.lora) exports 20 declarations. Import with use cookie;.

Overview

cookie implements RFC 6265 HTTP Cookie: and Set-Cookie: parsing, serialization, domain/path matching, expiration checks, and an in-memory jar. It validates token names, cookie-octet values, Domain attributes, and enforces SameSite=None requiring Secure.

SymbolPurpose
new, clone, format_set_cookie, parse_set_cookieConstruct, clone, format, and parse Set-Cookie headers
parse_cookies, format_cookie_header, pairParse and format Cookie: request headers
domain_matches, path_matches, default_path, is_expiredRFC 6265 scope and lifetime predicates
new_jar, jar_store, jar_header_for, jar_count, jar_clearStateful in-memory cookie jar with automatic expiry eviction

Valid Usage & Examples

Parse and format Set-Cookie and Cookie headers

Parse a Set-Cookie header in request context, inspect attributes, and round-trip it.

lora Allowed 
use cookie;

export fn main() void = {
	let sc = cookie::parse_set_cookie(
		"sid=abc123; Domain=.Example.COM; Path=/api; Max-Age=3600; Secure; HttpOnly; SameSite=Strict",
		"api.example.com",
		"/api/v1",
		1700000000i64,
	)!;
	assert(sc.domain == "example.com" && !sc.host_only);
	assert(sc.same_site == cookie::same_site::strict);
	let hdr = cookie::format_set_cookie(&sc)!;
	defer free(hdr);
}

Store cookies in a jar and generate request headers

Store multiple cookies, automatically skip Secure cookies on HTTP, and evict expired entries.

lora Allowed 
use cookie;

export fn main() void = {
	let j = cookie::new_jar();
	let t0 = 1700000000i64;
	cookie::jar_store(&j, "root=1; Path=/; Domain=example.com", "app.example.com", "/", t0)!;
	cookie::jar_store(&j, "sub=2; Path=/api; Secure", "app.example.com", "/api/v1", t0)!;

	let https_hdr = cookie::jar_header_for(&j, "app.example.com", "/api/v1", true, t0 + 10i64)!;
	defer free(https_hdr);
	assert(https_hdr == "sub=2; root=1");
}

Disallowed Forms & Diagnostics

Set SameSite=None without Secure

Both parse_set_cookie and format_set_cookie reject SameSite=None cookies that lack the Secure flag.

cookie::bad_cookie: invalid cookie: SameSite=None requires Secure
lora Rejected 
use cookie;

export fn main() void = {
	let c = cookie::parse_set_cookie("x=1; SameSite=None", "example.com")!; // error: SameSite=None requires Secure flag
}
lora Allowed 
use cookie;

export fn main() void = {
	let c = cookie::parse_set_cookie("x=1; Secure; SameSite=None", "example.com")!; // ok: includes Secure with SameSite=None
	assert(c.secure && c.same_site == cookie::same_site::none);
}

Constraints & Limits

Pre-1601 Expires
Ignored
Expires dates before year 1601 are ignored per RFC 6265.
Max-Age overflow
Saturated to i64::MAX
Huge Max-Age values saturate instead of wrapping.
