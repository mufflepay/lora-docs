Standard Library

sql — SQL databases: values, errors, a connection pool, transactions and rows

Module sql (lib/sql.lora) exports 106 declarations. Import with use sql;.

Overview

sql is Lora's driver-independent database layer: connection pooling (db[D, C]), transactions (tx[C]), parameter binding, and typed row mapping into Lora structs, slices, and scalars.

Drivers such as pg and sqlite implement sql::driver[C] and sql::link. Queries operate on any sql::source[C]—either a pool (*db[D, C]) or an active transaction (*tx[C]). sql::db[D, C] is @synchronised and manages idle and open connection limits across coroutines and threads; defer sql::close(&db) closes all pooled connections.

Row text and byte slices read via sql::first or sql::all are copied into a caller-supplied expanse::region (or sql::auto_region()), whereas sql::each passes a transient *T view valid only for the duration of the callback. sql::error is a tagged union covering server, conflict (SQLSTATE 23505 / 23P01), not_found, closed, protocol, unsupported, insecure, skipped, mismatch, bad_url, arity, net::error, net::unknown_host, and coro::error.

Valid Usage & Examples

Query scalars and typed structs with @column mapping

Map database columns to struct fields using @column, allocate row strings in an expanse::region, and stream rows with sql::each.

lora Allowed 
use expanse;
use fmt;
use sql;
use sqlite;
use uuid;

type customer = struct {
	@column(key, auto) id: i64,
	name: str,
	@column("nr_orders") orders: i32,
	country: ?str,
	@column("ref") key_ref: uuid::uuid,
	@column(skip) seen: bool,
}

export fn main() void = {
	let db = sqlite::open(":memory:")!;
	defer sql::close(&db);

	sql::script(&db, "create table customers (
		id integer primary key autoincrement,
		name text not null, nr_orders integer not null,
		country text, ref blob not null)")!;

	sql::exec(&db, "insert into customers (name, nr_orders, country, ref) values ($1, $2, $3, $4)",
		["Ada", 3i64, "uk", uuid::new()])!;

	let total = sql::scalar::[i64](&db, "select count(*) from customers", [])!;
	let r = expanse::reserve(expanse::MIB)!;
	defer expanse::finish(&r);

	let rows = sql::all::[customer](&db, &r, "select * from customers order by id", [])!;
	defer free(rows);

	for (let c .. rows) {
		fmt::println($"${c.id}: ${c.name} (${c.orders})")!;
	}
	assert(total == 1);
}

Transactions, savepoints, and automatic rollback

Use sql::transaction for automatic commit-on-void / rollback-on-error, or sql::begin with savepoint and rollback_to for fine-grained control.

lora Allowed 
use sql;
use sqlite;

export fn main() void = {
	let db = sqlite::open(":memory:")!;
	defer sql::close(&db);
	sql::script(&db, "create table ledger (id integer primary key, amount integer not null)")!;

	// Closure-scoped transaction rolls back on any error
	let res = sql::transaction(&db, fn(t: *sql::tx[sqlite::conn]) (void | sql::error | nomem) = {
		sql::exec(t, "insert into ledger (amount) values ($1)", [100i64])?;
		sql::savepoint(t, "before_bonus")!;
		sql::exec(t, "insert into ledger (amount) values ($1)", [50i64])!;
		sql::rollback_to(t, "before_bonus")!;
		sql::release_savepoint(t, "before_bonus")!;
	});
	res!;
	assert(sql::scalar::[i64](&db, "select sum(amount) from ledger", [])! == 100);
}

Compile-time checked @sql queries and batches

Use @sql(&db) for inline parameter interpolation and struct decoding, and sql::batch to run multiple statements atomically.

lora Allowed 
use fmt;
use pg;
use sql;

type user = struct { id: i64, name: str, email: ?str }

export fn main() void = {
	let db = pg::open("postgres://localhost/lora_demo?sslmode=disable", sql::limits { max_open = 4, ... })!;
	defer sql::close(&db);

	let name = "Cy";
	@sql(&db) "insert into users (name, email) values ({name}, null)"!;

	let counts: [2]u64 = [0...];
	sql::batch(&db, [
		sql::statement { text = "update users set email = $1 where name = $2", args = ["cy@example.com", name] },
		sql::statement { text = "delete from users where name = $1", args = ["nobody"] },
	], counts[..])!;

	let users = @sql(&db) "select id, name, email from users order by id" as user!;
	for (let u .. users) {
		fmt::println($"${u.id} ${u.name} ${u.email ?? "(no email)"}")!;
	}
}

Disallowed Forms & Diagnostics

Cannot decode NULL into a non-optional struct field

Reading a SQL NULL into a non-optional field (str, i64, etc.) fails at runtime with sql::mismatch; wrap nullable columns in ?T.

sql::mismatch: column country is null, which does not fit str
lora Rejected 
use expanse;
use sql;
use sqlite;

type strict_row = struct { country: str }

export fn main() void = {
	let db = sqlite::open(":memory:")!;
	defer sql::close(&db);
	sql::script(&db, "create table t (country text); insert into t values (null);")!;
	let r = expanse::reserve(4096)!;
	defer expanse::finish(&r);
	let _ = sql::all::[strict_row](&db, &r, "select country from t", [])!; // error: sql::mismatch (column country is NULL, cannot fit str)
}
lora Allowed 
use expanse;
use sql;
use sqlite;

type safe_row = struct { country: ?str } // ok: optional ?str accepts SQL NULL

export fn main() void = {
	let db = sqlite::open(":memory:")!;
	defer sql::close(&db);
	sql::script(&db, "create table t (country text); insert into t values (null);")!;
	let r = expanse::reserve(4096)!;
	defer expanse::finish(&r);
	let rows = sql::all::[safe_row](&db, &r, "select country from t", [])!;
	defer free(rows);
	assert(rows[0].country is void);
}

Constraints & Limits

Max result columns
128 (`MAX_COLUMNS`)
`sql::first`, `sql::all`, and `sql::each` reject results wider than 128 columns with `sql::unsupported`.
Max array dimensions
6 (`MAX_DIMENSIONS`)
Maximum dimensionality supported by `sql::array` decoding.
Default pool limits
`max_idle = 2`, others `0`
`sql::limits { ... }` defaults to 2 idle connections and unlimited open/lifetime/idle durations.
Error text buffer
120 bytes (`sql::text`)
Fixed inline buffer inside `protocol`, `unsupported`, `insecure`, `mismatch`, and `bad_url` errors.
Savepoint names
1..63 ASCII `[A-Za-z0-9_]`
Must not start with a digit; invalid names return `sql::bad_name`.
  • sql::all returns an owned slice ^[]T that must be freed with free(rows) while the expanse::region backing str/[]u8 fields remains alive.
  • Dropping a sql::tx[C] without calling commit or rollback closes its underlying connection, causing the server to roll back the transaction.

Module Guide & Examples

SQL databases: values, errors, a connection pool, transactions and rows read into structs, the same for every driver. A driver (pg, for PostgreSQL) speaks to its server; sql is what programs use.

let db = pg::open("postgres://app@localhost/shop")?; defer sql::close(&db); let n = sql::scalar::[i64](&db, "select count(*) from customers", [])?;

The @sql form writes queries as Lora: see docs/sql.md.
