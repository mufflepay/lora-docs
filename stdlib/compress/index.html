Standard Library

compress — DEFLATE, gzip and zlib

Module compress (lib/compress.lora) exports 29 declarations. Import with use compress;.

Overview

compress implements pure-Lora RFC 1951 DEFLATE compression and decompression alongside RFC 1952 gzip and RFC 1950 zlib framing. All readers and writers implement io::reader and io::writer so they compose directly with io::copy, io::read_all, and io::write_all.

  • DEFLATE: new_inflater(src) (stored, fixed Huffman, and dynamic Huffman blocks with a 32 KiB sliding window) and new_deflater(dst, level) (levels STORE = 0, FASTEST = 1, DEFAULT = 6, SMALLEST = 9, with 64 KiB block buffering and flush / finish).
  • gzip: new_gzip_reader(src) (automatically reads concatenated gzip members and verifies CRC-32 + ISIZE; exposes gzip_name) and new_gzip_writer(dst, level, name) with flush_gzip / finish_gzip.
  • zlib: new_zlib_reader(src) (verifies CMF/FLG and Adler-32 trailer) and new_zlib_writer(dst, level) with finish_zlib.
  • Bufferless mode: Passing void as dst to new_deflater, new_gzip_writer, or new_zlib_writer retains compressed bytes inside the deflater, readable via output(&d) and clear_output(&d).

Valid Usage & Examples

Compressing and decompressing gzip streams with filename metadata

Write compressed data to an io::buffer using new_gzip_writer, finalize with finish_gzip, and read it back via new_gzip_reader.

lora Allowed 
use compress;
use io;
use strings;

export fn main() (void | io::failure | nomem) = {
	let buf = io::new_buffer();
	let gw = compress::new_gzip_writer(&buf, compress::DEFAULT, "notes.txt")?;
	io::write_all(&gw, strings::to_bytes("hello compressed world"))?;
	compress::finish_gzip(&gw)?;

	let src = io::new_bytes_reader(io::bytes_of(&buf));
	let gr = compress::new_gzip_reader(&src);
	let plain = io::read_all(&gr, 1 << 20)?;
	assert(compress::gzip_name(&gr) == "notes.txt");
	assert(strings::from_bytes(plain) == "hello compressed world");
}

Flushing a raw DEFLATE stream mid-flight

Call compress::flush(&d) to emit a sync-flushed block so an inflater can read bytes before compress::finish(&d) is called.

lora Allowed 
use compress;
use io;
use strings;

export fn main() (void | io::failure | nomem) = {
	let out = io::new_buffer();
	let d = compress::new_deflater(&out, compress::FASTEST)?;
	io::write_all(&d, strings::to_bytes("part one, "))?;
	compress::flush(&d)?;

	let src = io::new_bytes_reader(io::bytes_of(&out));
	let inf = compress::new_inflater(&src);
	let tmp: [32]u8 = [0...];
	let n = inf.read(tmp)? as usize;
	assert(strings::from_bytes(tmp[..n]) == "part one, ");

	io::write_all(&d, strings::to_bytes("part two"))?;
	compress::finish(&d)?;
}

Using zlib and bufferless (`dst = void`) deflater output

Round-trip data with new_zlib_writer / new_zlib_reader, or pass void to new_gzip_writer and drain bytes via compress::output and compress::clear_output.

lora Allowed 
use compress;
use io;
use strings;

export fn main() (void | io::failure | nomem) = {
	let out = io::new_buffer();
	let zw = compress::new_zlib_writer(&out, compress::SMALLEST)?;
	io::write_all(&zw, strings::to_bytes("zlib payload"))?;
	compress::finish_zlib(&zw)?;

	let src = io::new_bytes_reader(io::bytes_of(&out));
	let zr = compress::new_zlib_reader(&src);
	let got = io::read_all(&zr, 1 << 20)?;
	assert(strings::from_bytes(got) == "zlib payload");
}

Disallowed Forms & Diagnostics

Ignoring `io::failure` / `nomem` on `new_gzip_writer` or `finish_gzip`

Deflater constructors and finish* functions return error unions (nomem / io::failure) that must be handled or propagated (L0003).

L0003: Unhandled error: (io::failure | nomem) must be propagated or handled

use compress;
use io;

export fn main() void = {

	compress::finish_gzip(&gw);
}

Constraints & Limits

DEFLATE sliding window
32 KiB (`WINDOW = 32768`)
Maximum LZ77 back-reference distance in RFC 1951.
Deflater block size
64 KiB (`BLOCK = 65536`)
Buffered input size before emitting a compressed or stored block.
Compression levels
0 (`STORE`) to 9 (`SMALLEST`)
Defaults to `DEFAULT = 6`; `FASTEST = 1`.
  • Always call finish, finish_gzip, or finish_zlib when done writing; otherwise the final DEFLATE block marker (BFINAL) and gzip/zlib checksum trailers are not written.
  • Corrupt or truncated streams yield io::invalid or io::unexpected_end from read.

Module Guide & Examples

DEFLATE (RFC 1951), and gzip (RFC 1952) and zlib (RFC 1950) around it: readers that decompress what they read, and writers that compress what they are given, as streams.

let z = compress::new_gzip_reader(&file)?; let text = io::read_all(&z, 1 << 20)?; // a limit: a small input // can grow enormously let out = io::new_buffer(); let w = compress::new_gzip_writer(&out, compress::DEFAULT)?; io::write_all(&w, data)?; compress::finish_gzip(&w)?;

A reader checks what it reads: Huffman codes that are not codes, distances back past what came before, a checksum or length that does not match, are each an io::invalid that says what and where.

Streams of DEFLATE (RFC 1951), and of the gzip (RFC 1952) and zlib (RFC 1950) formats around it.

Reading. An inflater, gzip_reader or zlib_reader is an io::reader that decompresses what it reads from its source:

  • A gzip stream may hold many members, one after another, and each is checked by its CRC-32 and length. A zlib stream is checked by its Adler-32.
  • Data that is not a stream, or does not check, is io::invalid, at the byte it was found. A stream cut short is io::unexpected_end.
  • A read gives what has come out once a block ends, so a stream flushed partway can be read up to the flush.

Writing. A deflater, gzip_writer or zlib_writer is an io::writer that compresses what is written to it, at a level from STORE (0) to SMALLEST (9):

  • Each block is coded in whichever is smallest: dynamic codes, fixed codes, or stored.
  • flush, flush_gzip or the zlib writer's flush(&w.d) sends what was written so far, so a reader can have all of it. The stream goes on after.
  • finish, finish_gzip or finish_zlib ends the stream.
  • With void for the destination, what is made is kept: output gives it, and clear_output clears it once it has been sent on.

use io;
use strings;

	compress::finish_gzip(&g)!;

}
