Standard Library

io — readers and writers

Module io (lib/io.lora) exports 80 declarations. Import with use io;.

Overview

io defines Lora's core streaming interfaces, error model, descriptor wrappers, and in-memory adapters. Files, sockets, pipes, TLS sessions, and memory buffers all implement the same interfaces (reader, writer, closer, seeker, reader_at, writer_at, byte_reader), so helpers like io::copy, io::read_all, and io::write_all work uniformly across transports.

Every stream operation shares the io::failure tagged union: (error | unexpected_end | closed | short_write | timed_out | too_large | invalid | nomem). Standard streams are exposed as non-owning io::file globals: io::stdin (fd 0), io::stdout (fd 1), and io::stderr (fd 2).

Valid Usage & Examples

Bounded reading and exact-length reads

Use io::read_all with an explicit byte cap to prevent unbounded memory growth, and io::read_full for fixed-size headers.

lora Allowed 
use fmt;
use io;
use strings;

export fn main() void = {
	let r = io::new_str_reader("HDR1payload");
	let hdr: [4]u8 = [0...];
	io::read_full(&r, hdr[..])!;

	let body = io::read_all(&r, 1024)!;
	defer free(body);
	fmt::printfn("hdr={} body={}", strings::from_bytes(hdr[..]), strings::from_bytes(body))!;
}

Composing tee_reader, counter, and multi_writer

Fan out writes to multiple destinations while counting bytes and teeing a stream.

lora Allowed 
use fmt;
use io;

export fn main() void = {
	let src = io::new_str_reader("streamed payload");
	let dst_a = io::new_buffer();
	let dst_b = io::new_buffer();
	let ws: [2]io::writer = [&dst_a, &dst_b];
	let mw = io::new_multi_writer(ws[..]);
	let cnt = io::new_counter(&mw);

	let copied = io::copy(&cnt, &src)!;
	fmt::printfn("copied={} count={} a={}", copied, cnt.count, io::str_of(&dst_a))!;
}

Zero-allocation fixed_writer and section reader_at

Write into a stack buffer with io::fixed_writer and read a bounded slice with io::new_section.

lora Allowed 
use fmt;
use io;
use strings;

export fn main() void = {
	let backing: [16]u8 = [0...];
	let fw = io::fixed_writer(backing[..]);
	io::write_str(&fw, "0123456789")!;

	let br = io::new_bytes_reader(io::written(&fw));
	let sec = io::new_section(&br, 2, 5);
	let out = io::read_all(&sec, 64)!;
	defer free(out);
	fmt::printfn("section={}", strings::from_bytes(out))!;
}

Vectored writes to a file descriptor

Use io::write_vec_all to combine header and body slices in minimal writev syscalls.

lora Allowed 
use io;
use strings;

export fn main() void = {
	let parts: [2][]const u8 = [
		strings::to_bytes("hello "),
		strings::to_bytes("world\n"),
	];
	io::write_vec_all(&io::stdout, parts[..])!;
}

Disallowed Forms & Diagnostics

Ignoring io::failure on io::read_all or io::write_all

io::read_all returns (^[]u8 | io::failure) and io::at_most returns io::too_large if input exceeds the cap.

E0308: cannot return (^[]u8 | io::failure) from function returning ^[]u8
lora Rejected 
use io;

export fn bad() ^[]u8 = {
	let r = io::new_str_reader("too long");
	let capped = io::at_most(&r, 3);
	return io::read_all(&capped, 64); // error: return type ^[]u8 omits io::failure
}
lora Allowed 
use io;

export fn good() (^[]u8 | io::failure) = { // ok: return union includes io::failure
	let r = io::new_str_reader("too long");
	let capped = io::at_most(&r, 3);
	return io::read_all(&capped, 64);
}

Constraints & Limits

64 buffers
`io::file_write_vec` packs up to 64 non-empty slices per `writev` call.

80 bytes max
`io::invalid_at` truncates `why` at a UTF-8 rune boundary within 80 bytes.
Zero-read guard
100 consecutive 0-reads
`io::read_full` and `io::read_at_least` return `io::unexpected_end` after >100 zero-byte reads.
Default copy buffers
8 KiB / 16 KiB
`reader.write_to` and `copy_n` use 8 KiB stack buffers; `copy_file` uses 16 KiB.
  • io::file does not implement rt::drop and does not own its descriptor; use fs::file for RAII descriptor closing, or call io::file_close explicitly.
  • io::read_all(r, limit) reads up to limit bytes and returns io::too_large if more data remains.

Module Guide & Examples

Reading and writing bytes.

A reader gives bytes as they come, and a writer takes them. Files, network connections, TLS sessions, buffers in memory, compressed streams and message bodies are all readers or writers, so what is written for one works for every other: io::copy(&out, &in) moves a file to a socket as it moves a buffer to a file.

type reader = interface { fn read(buf: []u8) (usize | done | failure); ... }; type writer = interface { fn write(buf: []const u8) (usize | failure); }; type closer = interface { fn close() (void | failure); };

A type implements each on its own, and with them every interface made of them: a type with an impl of reader and one of closer is a read_closer too.

What fails says why, with one set of errors, failure, that every stream shares: the system's error number, input that ended early, a closed stream, a deadline, a limit, data that does not make sense and where, or running out of memory.

A reader gives bytes as they come and a writer takes them. Files, sockets, TLS connections, buffers in memory and every module's streams are readers or writers, so what is written for one works for each: io::copy(&out, &in) moves a file to a socket as it moves a buffer to a file. A type implements each interface by itself, and with them every interface made of them: one with impls of reader and closer is a read_closer too, and a value of a larger interface passes as any part of it.

lora 
use io;
use strings;

export fn main() void = {
	let src = io::new_str_reader("one two three");
	let out = io::new_buffer();
	let first = io::limit(&src, 3);
	assert(io::copy(&out, &first)! == 3);
	assert(io::str_of(&out) == "one");
	let rest = io::read_all(&src, 100)!;
	assert(strings::from_bytes(rest[..]) == " two three");
}
