sync — synchronization primitives and typed atomics

Module sync (lib/sync.lora) exports 101 declarations. Import with use sync;.

Overview

Higher-level synchronization primitives and typed atomics built on thread.

sync wraps thread::atomic, thread::mutex, and thread::cond into ergonomic, type-safe concurrency building blocks with automatic drop cleanup for OS mutexes and condition variables.

Valid Usage & Examples

Coordinating worker threads with wait_group and typed atomics

Use sync::wait_group and sync::atomic_u64 to wait for multiple OS threads to complete and collect a lock-free sum.

lora Allowed 
use arc;
use sync;
use thread;

type state = struct {
	wg: sync::wait_group,
	sum: sync::atomic_u64,
}

export fn main() void = {
	let st = arc::new(state {
		wg = sync::wg_new(),
		sum = sync::u64_new(0u64),
	})!;
	sync::wg_add(&arc::get(&st).wg, 3);
	for (let i = 1u64; i <= 3u64; i += 1u64) {
		let s = arc::share(&st);
		let _ = thread::spawn_with(s, fn(sp: arc::arc[state]) void = {
			let p = arc::get(&sp);
			sync::u64_fetch_add(&p.sum, 10u64);
			sync::wg_done(&p.wg);
		})!;
	}
	sync::wg_wait(&arc::get(&st).wg);
	assert(sync::u64_load(&arc::get(&st).sum) == 30u64);
}

Lazy thread-safe initialization with once_cell[T]

Initialize a shared value on first access across threads using sync::once_cell_get_or_init.

lora Allowed 
use sync;

export fn main() void = {
	let cell = sync::once_cell_new::[int]();
	assert(!sync::once_cell_is_set(&cell));
	let ptr = sync::once_cell_get_or_init(&cell, fn() int = 4096)!;
	assert(*ptr == 4096);
	let was_set = sync::once_cell_set(&cell, 9999)!;
	assert(!was_set);
	let taken = sync::once_cell_take(&cell);
	assert(taken is int && taken as int == 4096);
}

Writer-preferring rwlock and cyclic barrier

Protect read-heavy data with sync::rwlock and synchronize phases across threads with sync::barrier.

lora Allowed 
use sync;

export fn main() void = {
	let rw = sync::rwlock_new();
	let value = 0;
	sync::rwlock_with_write(&rw, fn() void = {
		value = 123;
	});
	sync::rwlock_with_read(&rw, fn() void = {
		assert(value == 123);
	});

	let b = sync::barrier_new(1z);
	let is_leader = sync::barrier_wait(&b);
	assert(is_leader);
}

Disallowed Forms & Diagnostics

Creating a barrier with zero parties or negative latch count

Calling barrier_new(0z) or latch_new(-1) violates precondition assertions and aborts at runtime; always pass positive party counts and non-negative latch counts.

E_ASSERT_FAILED: assertion failed: parties > 0z
lora Rejected 
use sync;

export fn main() void = {
	let b = sync::barrier_new(0z); // error: assertion failed: parties > 0z
	let _ = sync::barrier_wait(&b);
}
lora Allowed 
use sync;

export fn main() void = {
	let b = sync::barrier_new(2z); // ok: positive party count satisfies precondition
	let _ = b;
}

Constraints & Limits

RwLock scheduling
Writer-preferring
Waiting writers block new readers (waiting_writers > 0) to prevent writer starvation.
once_cell[T] allocation
Heap-boxed T
once_cell_set and once_cell_get_or_init allocate a heap box for T and return (bool | nomem) or (*T | nomem).
Target context
OS threads
Primitives block the calling OS thread via pthread mutex/cond; inside coroutines, prefer coro::chan or coro::serial.
