Standard Library

stats — Descriptive and Welford streaming statistics

Module stats (lib/stats.lora) exports 34 declarations. Import with use stats;.

Overview

stats provides descriptive batch statistics and Welford/Chan streaming statistics over []const f64 slices.

Batch summation uses Neumaier compensated summation (sum, geometric_mean, harmonic_mean) to preserve precision across large cancellations. Variance and Pearson correlation use two-pass / max-scaled formulations to avoid catastrophic cancellation and intermediate overflow. Streaming accumulators (online) use Welford's single-pass recurrence and Chan's parallel online_merge.

Valid Usage & Examples

Batch descriptive statistics, percentiles, and linear regression

Compute mean, standard deviation, quantiles, Pearson correlation, and OLS regression with proper error handling.

lora Allowed 
use stats;
use math;

export fn main() (void | stats::stats_error | nomem) = {
	let xs: [5]f64 = [2.0, 4.0, 4.0, 4.0, 6.0];
	assert(math::fabs(stats::mean(xs[..])? - 4.0) < 1e-12);
	assert(math::fabs(stats::sample_variance(xs[..])? - 2.0) < 1e-12);
	assert(math::fabs(stats::median(xs[..])? - 4.0) < 1e-12);

	let ps: [3]f64 = [0.0, 50.0, 100.0];
	let q = stats::percentiles(xs[..], ps[..])?;
	defer free(q);
	assert(q[0] == 2.0 && q[2] == 6.0);

	let x: [4]f64 = [1.0, 2.0, 3.0, 4.0];
	let y: [4]f64 = [3.0, 5.0, 7.0, 9.0];
	let reg = stats::linear_regression(x[..], y[..])?;
	assert(math::fabs(reg.slope - 2.0) < 1e-12);
	assert(math::fabs(reg.intercept - 1.0) < 1e-12);
}

Streaming Welford accumulators and Chan parallel merge

Accumulate statistics in two independent streams and merge them in O(1) without storing samples.

lora Allowed 
use stats;
use math;

export fn main() void = {
	let a = stats::online_new();
	let b = stats::online_new();
	stats::online_push(&a, 2.0);
	stats::online_push(&a, 4.0);
	stats::online_push(&b, 4.0);
	stats::online_push(&b, 4.0);
	stats::online_push(&b, 6.0);

	let merged = stats::online_merge(&a, &b);
	assert(stats::online_count(&merged) == 5u64);
	assert(math::fabs(stats::online_mean(&merged) - 4.0) < 1e-12);
	assert(math::fabs(stats::online_sample_variance(&merged) - 2.0) < 1e-12);
	assert(stats::online_min(&merged) == 2.0);
	assert(stats::online_max(&merged) == 6.0);
}

Disallowed Forms & Diagnostics

Ignoring the `(f64 | stats_error)` error union on empty-slice inputs

Functions like mean, variance, sample_variance, and pearson return error unions and cannot be used directly as f64.

L0301: cannot use `(f64 | stats::stats_error)` as `f64`
lora Rejected 
use stats;

export fn main() void = {
	let empty: [0]f64 = [];
	let m: f64 = stats::mean(empty[..]); // error: unhandled stats_error
}
lora Allowed 
use stats;

export fn main() void = {
	let empty: [0]f64 = [];
	let m = stats::mean(empty[..]) or 0.0; // ok: handle stats_error with fallback
	assert(m == 0.0);
}

Constraints & Limits

Sample Variance Minimum
N >= 2
`sample_variance`, `covariance`, `pearson`, and `linear_regression` return `stats_error` if `len < 2`.
Percentile Range
[0.0, 100.0]
Values outside `[0, 100]` or `NaN` return `stats_error`.
Order Stats Memory
O(N) heap copy
`percentile`, `percentiles`, `median`, and `iqr` allocate and sort a temporary `^[]f64` copy.
NaN Propagation
Consistent
`min_val`, `max_val`, `percentile`, `iqr`, and `online` propagate `NaN`.
