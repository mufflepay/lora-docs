Standard Library

testing — native test, benchmark, and fuzzing framework

Module testing (lib/testing.lora) exports 51 declarations. Import with use testing;.

Overview

testing is Lora's native unit testing, benchmarking, and fuzzing framework. It powers both @test / @bench / @fuzz declarations (run via lora test or run_registered*) and explicit testing::suite runners.

Each test context *testing::t provides:

  • Scoped resources: region(t) (auto-freed expanse::region), temp_dir(t) (auto-removed /tmp/lora-test-*), and LIFO cleanup(t, f).
  • Allocation & leak budgets: no_allocs, max_allocs, no_leaks, allocs_of, snapshot_allocs, and per-test leak checking (disable per test with allow_leaks(t)).
  • Assertions: check, eq, require_eq, ne, approx, eq_lines (with unified diff on mismatch), contains, ok, err, is_ok, is_err, is_void, fail, fatal, skip.
  • Benchmarks & Fuzzing: Go-style testing::loop(b) with start_timer/stop_timer/reset_timer/keep, and coverage-free mutation fuzzing (fuzz, fuzz_bytes, seed, seed_str) with input shrinking.

Valid Usage & Examples

Test suite with subtests, temp_dir, and allocation budgets

Combine testing::suite_new, testing::temp_dir, testing::eq, and testing::no_allocs / testing::no_leaks.

lora Allowed 
use fs;
use strings;
use testing;

fn sum(n: i64) i64 = {
	let s = 0i64;
	for (let i = 0i64; i < n; i += 1) s += i;
	return s;
}

export fn main() void = {
	let s = testing::suite_new();
	testing::suite_run(&s, "io_and_allocs", fn(t: *testing::t) void = {
		let dir = testing::temp_dir(t)!;
		testing::check(t, fs::exists(dir)!);

		testing::no_allocs(t, fn() void = {
			let v = sum(100);
			testing::keep(&v);
		});

		testing::no_leaks(t, fn() void = {
			let p = strings::clone("ok")!;
			free(p);
		});
	});
	assert(testing::suite_ok(&s));
}

Benchmarks with testing::loop and testing::keep

Write adaptive benchmarks using testing::bench and testing::loop(b), preventing dead-code elimination with testing::keep.

lora Allowed 
use fmt;
use testing;

export fn main() void = {
	let res = testing::bench("add_loop", fn(b: *testing::b) void = {
		for (testing::loop(b)) {
			let x = 0u64;
			for (let i = 0u64; i < 64; i += 1) x += i;
			testing::keep(&x);
		}
	}, 10);
	let line = testing::format_bench(&res)!;
	defer free(line);
	fmt::println(line)!;
}

Property fuzzing with seeds and automatic shrinking

Seed a fuzz target with testing::seed_str and test invariants across mutated byte inputs with testing::fuzz_bytes.

lora Allowed 
use testing;

export fn main() void = {
	let res = testing::fuzz("max_len_check", fn(f: *testing::f) void = {
		testing::seed_str(f, "hello");
		testing::fuzz_bytes(f, fn(t: *testing::t, data: []const u8) void = {
			testing::check(t, len(data) <= 1024);
		});
	}, testing::fuzz_options { max_iters = 100, max_len = 512, shrink = true, ... });
	assert(!res.failed);
}

Disallowed Forms & Diagnostics

Do not expect execution to continue after testing::fatal or testing::require_eq failure

testing::fatal and testing::require_eq abort the current test coroutine immediately via unit::fail / panic semantics, skipping subsequent checks in that test body (though defer and t teardown still run).

test_fatal_abort: testing::require_eq aborts the active test immediately on mismatch
lora Rejected 
use testing;

export fn main() void = {
	let s = testing::suite_new();
	testing::suite_run(&s, "early_abort", fn(t: *testing::t) void = {
		testing::require_eq(t, 1, 2, "must match"); // error: aborts the subtest immediately on mismatch
		testing::eq(t, 2, 2);
	});
}
lora Allowed 
use testing;

export fn main() void = {
	let s = testing::suite_new();
	testing::suite_run(&s, "soft_checks", fn(t: *testing::t) void = {
		testing::eq(t, 1, 2, "first check"); // ok: records failure and continues to remaining checks
		testing::eq(t, 2, 2, "second check");
	});
}

Constraints & Limits

Environment overrides
`LORA_TEST_FILTER`, `LORA_TEST_JSON`
`suite_new` reads `LORA_TEST_FILTER` when `opts.filter` is empty and `LORA_TEST_JSON=1|true` when `opts.json` is false.
Benchmark iteration cap
10,000,000 iterations (`min_ms` default `20`)
`testing::bench` scales `n` until `elapsed_ns >= min_ms * 1_000_000` or `n >= 10_000_000`.
Default fuzz options
`max_iters = 500`, `max_len = 512`, `shrink = true`
Default PRNG seed is `0x9e3779b97f4a7c15`.

Module Guide & Examples

Native Lora testing, benchmarking, and fuzzing framework.

let s = testing::suite_new(); testing::suite_run(&s, "math", fn(t: *testing::t) void = { testing::eq(t, 2 + 2, 4); }); assert(testing::suite_ok(&s));

Provides testing::t, testing::b, testing::f, reflection-powered assertions (eq, neq, gt, lt, contains, matches, is_err, is_ok, ok), snapshot/golden testing (snapshot), table-driven cases, isolated temp_dir + defer/cleanup, bench_loop / keep, and fuzz_bytes / fuzz_str, integrated with @test, @bench, @fuzz, and lora test.
