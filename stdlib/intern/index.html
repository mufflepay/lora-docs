Standard Library

intern — Arena-backed string interner

Module intern (lib/intern.lora) exports 13 declarations. Import with use intern;.

Overview

intern maps unique str values to compact u32 symbol IDs (sym) so string equality becomes a single integer comparison. Interned string bytes are stored in an arena::arena (never moving on growth), indexed by a map::map[str, u32] for O(1) deduplication and a ^[]str table for O(1) resolve. Implements drop via finish.

Valid Usage & Examples

Interning, deduplicating, and resolving symbols

Equal strings always yield the same sym ID, and resolve returns a borrowed str view in O(1).

lora Allowed 
use intern;

export fn main() void = {
	let in = intern::new();
	defer intern::finish(&in);

	let a = intern::intern(&in, "hello")!;
	let b = intern::intern(&in, "world")!;
	let c = intern::intern(&in, "hello")!;

	assert(a == c && a != b);
	assert(intern::resolve(&in, a) as str == "hello");
	assert(intern::resolve(&in, intern::INVALID_SYM) is void);
}

Pre-sizing, non-inserting lookup, and clearing for reuse

Use lookup or contains to query without allocating, and clear to reset the interner while retaining arena chunks.

lora Allowed 
use intern;

export fn main() void = {
	let in = intern::with_capacity(16)!;
	defer intern::finish(&in);

	let id = intern::intern(&in, "token")!;
	assert(intern::contains(&in, "token"));
	assert(intern::lookup(&in, "token") as intern::sym == id);
	assert(intern::lookup(&in, "missing") is void);

	intern::clear(&in);
	assert(intern::is_empty(&in));
}

Disallowed Forms & Diagnostics

Using a resolved string after clearing or finishing the interner

intern::resolve is marked @views(in), so the returned str borrows from the interner and cannot be used after clear, finish, or drop.

Compile error: cannot use borrowed value s after in is mutated by intern::clear
lora Rejected 
use intern;

export fn main() void = {
	let in = intern::new();
	let id = intern::intern(&in, "hello")!;
	let s = intern::resolve(&in, id) as str;
	intern::clear(&in);
	assert(s == "hello"); // error: s borrows from in, invalidated by intern::clear
}

Clone the resolved str with strings::clone if it must outlive clear or finish.

lora Allowed 
use intern;
use strings;

export fn main() void = {
	let in = intern::new();
	let id = intern::intern(&in, "hello")!;
	let s = strings::clone(intern::resolve(&in, id) as str)!; // ok: cloned ^str outlives intern::clear
	intern::clear(&in);
	assert(s == "hello");
}

Module Guide & Examples

String interner mapping unique strings to compact u32 symbol IDs.

Interned strings are stored in a chunked arena so pointers never move on growth. Equal strings always produce the same sym ID, enabling O(1) equality checks and fast reverse lookup.

let in = intern::new(); defer intern::finish(&in); let a = intern::intern(&in, "hello")!; let b = intern::intern(&in, "hello")!; assert(a == b); assert(intern::resolve(&in, a)! == "hello");

Deduplicates strings into compact sym (u32) handles for O(1) equality and fast reverse lookup (new, with_capacity, intern, lookup, contains, resolve, count, is_empty, clear, finish).

lora 
let in = intern::new();
defer intern::finish(&in);
let a = intern::intern(&in, "key")!;
assert(intern::resolve(&in, a) as str == "key");
