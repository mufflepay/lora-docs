Standard Library

url — URLs and their parts

Module url (lib/url.lora) exports 46 declarations. Import with use url;.

Overview

url implements RFC 3986 URL parsing, reference resolution, construction, percent-encoding/decoding, and application/x-www-form-urlencoded query string manipulation. A parsed url::url owns a single normalized copy of its text, and accessor functions (scheme, hostname, port, path, query, fragment) return zero-copy slices into that buffer.

Parsing is strict: unescaped disallowed characters, truncated %xx escapes, invalid IPv6 literals, or out-of-range ports return url::invalid with the byte offset and reason. Separate helpers (path_text, password_text, path_segments, redacted) decode or redact components on demand.

Valid Usage & Examples

Parse a URL, inspect components, and redact credentials

Extract scheme, unescaped path, IPv6 host address, request target, and password-redacted URL string.

lora Allowed 
use netip;
use url;

export fn main() void = {
	let u = url::parse("https://ann:s%40cret@example.com:8443/a%20b/c?q=1#top")!;
	assert(url::is_scheme(&u, "HTTPS"));
	assert(url::hostname(&u) == "example.com");
	assert(url::port_number(&u) as u16 == 8443);

	let p = url::path_text(&u)!;
	defer free(p);
	assert(p == "/a b/c");

	let red = url::redacted(&u)!;
	defer free(red);
	assert(red == "https://ann:xxxxx@example.com:8443/a%20b/c?q=1#top");
}

Resolve relative references and join path segments

Apply RFC 3986 reference resolution against a base URL and safely append path segments with dot-segment removal.

lora Allowed 
use url;

export fn main() void = {
	let base = url::parse("https://api.example.com/v1/users/list?active=1")!;
	let rel = url::parse("../42/profile?full=true")!;
	let resolved = url::resolve(&base, &rel)!;
	assert(url::text(&resolved) == "https://api.example.com/v1/42/profile?full=true");

	let joined = url::join_path(&base, ["a b", "../c"])!;
	assert(url::path(&joined) == "/v1/users/list/c");
}

Parse, update, and encode query parameters

Parse a query string, read multi-valued keys, update entries, and serialize back in sorted canonical order.

lora Allowed 
use url;

export fn main() void = {
	let q = url::parse_query("b=2&a=1&a=hello+world")!;
	assert(url::get(&q, "a") as str == "1");
	url::set(&q, "b", "3&4")!;
	url::add(&q, "a", "z")!;
	let encoded = url::encode(&q)!;
	defer free(encoded);
	assert(encoded == "a=1&a=hello+world&a=z&b=3%264");
}

Disallowed Forms & Diagnostics

Parse URLs with unescaped spaces or malformed percent-escapes

Spaces and incomplete % escapes are rejected immediately by url::parse with url::invalid.

reason::bad_char: cannot parse "http://example.com/a b" as a URL: a character it cannot hold unescaped, at byte 20
lora Rejected 
use url;

export fn main() void = {
	let u = url::parse("http://example.com/a b")!; // error: unescaped space in path returns url::invalid
}
lora Allowed 
use url;

export fn main() void = {
	let escaped = url::escape("a b", url::part::path)!;
	defer free(escaped);
	let u = url::build(url::parts { scheme = "http", host = "example.com", path = "/a b" })!; // ok: url::build percent-encodes path characters
	assert(url::text(&u) == "http://example.com/a%20b");
}

Constraints & Limits

Max URL length
4 GiB (u32 spans)
Spans use u32 offsets/lengths; longer inputs fail with reason::too_long.
Port range
0..65535
Non-numeric or >65535 ports fail with reason::bad_port.

Module Guide & Examples

URLs as RFC 3986 has them: parsed, checked, resolved against a base, built from parts, with their parts escaped and unescaped, and query strings as values.

let u = url::parse("https://ann:secret@example.com:8443/a%20b?q=1&q=2#top")?; url::scheme(&u) // "https" url::hostname(&u) // "example.com" url::port(&u) // "8443" url::path(&u) // "/a%20b", as written let p = url::path_text(&u)?; // "/a b", unescaped let q = url::query_values(&u)?; url::get(&q, "q") // "1" let r = url::resolve(&u, &url::parse("../c?x")?)?; // https://...:8443/c?x

A URL owns one copy of its text, and its parts are views of it: what was written, escapes and all. Parsing is strict: a character a URL cannot hold unescaped, a bad escape, a bad port or IPv6 address is an error that says what and at which byte:

cannot parse "http://a b/" as a URL: a character it cannot hold unescaped, at byte 8

use url;

export fn main() void = {
	let u = url::parse("https://ann@example.com:8443/a%20b?q=1#top")!;
	assert(url::hostname(&u) == "example.com" && url::port(&u) == "8443");
	let p = url::path_text(&u)!;
	assert(p == "/a b");
	let r = url::resolve(&u, &url::parse("../c?x")!)!;
	assert(url::text(&r) == "https://ann@example.com:8443/c?x");
	let q = url::query_values(&u)!;
	assert(url::get(&q, "q") as str == "1");
}
