utf16 — UTF-16 encoding, decoding, and BOM detection

Module utf16 (lib/utf16.lora) exports 20 declarations. Import with use utf16;.

Overview

UTF-16 encoding, decoding, surrogate pair validation, BOM detection, and little/big-endian byte serialization.

utf16 supports both native u16 code-unit slices and raw u8 byte streams in little-endian (_le) or big-endian (_be) order. Strict decoders return (^str | decode_err | nomem), while _lossy variants replace unpaired surrogates or trailing odd bytes with REPLACEMENT_CHAR (U+FFFD).

Valid Usage & Examples

Encoding and strictly decoding native UTF-16 code units

Compute unit length, encode a UTF-8 string into ^[]u16, validate it, and decode back to ^str.

lora Allowed 
use utf16;

export fn main() (void | utf16::decode_err | nomem) = {
	let orig = "Hello, 世界 🚀!";
	assert(utf16::encoded_len(orig) == 13z);

	let units = utf16::encode(orig)?;
	defer free(units);
	assert(utf16::validate(units[..]));

	let back = utf16::decode(units[..])?;
	defer free(back);
	assert(back == orig);
}

Endian byte encoding and BOM auto-detection

Serialize UTF-16BE / UTF-16LE bytes and decode BOM-prefixed payloads with decode_bom.

lora Allowed 
use utf16;

export fn main() (void | utf16::decode_err | nomem) = {
	let with_be_bom: [6]u8 = [0xFE, 0xFF, 0x00, 'A', 0x00, 'B'];
	let s = utf16::decode_bom(with_be_bom[..])?;
	defer free(s);
	assert(s == "AB");

	let le = utf16::encode_le("🚀")?;
	defer free(le);
	let decoded = utf16::decode_le(le[..])?;
	defer free(decoded);
	assert(decoded == "🚀");
}

Lossy decoding for untrusted UTF-16 input

Use decode_lossy or decode_le_lossy when unpaired surrogates or odd byte lengths should become U+FFFD.

lora Allowed 
use utf16;

export fn main() (void | nomem) = {
	let mixed: [3]u16 = ['A', 0xD800, 'B'];
	assert(!utf16::validate(mixed[..]));

	let lossy = utf16::decode_lossy(mixed[..])?;
	defer free(lossy);
	assert(lossy == "A\uFFFDB");

	let odd_le: [3]u8 = ['A', 0, 'B'];
	let le_lossy = utf16::decode_le_lossy(odd_le[..])?;
	defer free(le_lossy);
	assert(le_lossy == "A\uFFFD");
}

Disallowed Forms & Diagnostics

Ignoring decode_err when calling strict decoders

decode, decode_le, decode_be, and decode_bom return (^str | decode_err | nomem). Failing to handle decode_err is a type error.

L0200: unhandled error variant utf16::decode_err in return union
lora Rejected 
use utf16;

export fn main() (void | nomem) = {
	let bad: [1]u16 = [0xD800];
	let s: ^str = utf16::decode(bad[..])?; // error: utf16::decode_err is not in return union
	free(s);
}
lora Allowed 
use utf16;

export fn main() (void | utf16::decode_err | nomem) = { // ok: return union includes utf16::decode_err
	let bad: [1]u16 = [0xD800];
	let s = utf16::decode(bad[..])?;
	defer free(s);
}

Constraints & Limits

Surrogate ranges
0xD800..0xDBFF / 0xDC00..0xDFFF
High surrogates followed by non-low surrogates fail strict decoding with `decode_err`.
Odd byte lengths
Strict error / Lossy U+FFFD
`decode_le` and `decode_be` return `decode_err` on odd `len(b)`; `_lossy` appends one `U+FFFD`.
BOM fallback
Little-endian default
`decode_bom` strips `FF FE` (LE) or `FE FF` (BE) and defaults to LE if neither BOM is present.

Module Guide & Examples

UTF-16 encoding, decoding, surrogate pair validation, and LE/BE conversion.

let units = utf16::encode("hello 🚀")!; defer free(units); let s = utf16::decode(units)!; defer free(s); assert(s == "hello 🚀");

Strict and lossy UTF-16 code-unit and LE/BE byte codecs with surrogate-pair helpers (encode, decode, decode_lossy, encode_le, encode_be, decode_le, decode_be, decode_le_lossy, decode_be_lossy, decode_bom, encoded_len, validate, encode_rune, decode_surrogate_pair).

lora

defer free(le);
let s = utf16::decode_le(le)!;
defer free(s);
