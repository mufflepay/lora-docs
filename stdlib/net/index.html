Standard Library

net — connections

Module net (lib/net.lora) exports 75 declarations. Import with use net;.

Overview

net provides non-blocking TCP, UDP, and Unix domain sockets (conn, listener, packet_conn) that integrate with Lora's coroutine scheduler (kqueue) when running in a coroutine and block cleanly outside one. Sockets are RAII owners via impl drop: dropping a conn, listener, or packet_conn closes the underlying descriptor once, and Unix listeners unlink their socket path on close.

Every conn and packet_conn implements io::reader, io::writer, and io::closer. Deadlines are absolute u64 millisecond timestamps (created with net::after(ms)); expired operations return net::error with net::is_timeout(&e) == true (or io::timed_out via io traits) without invalidating the socket if the deadline is later cleared or moved.

Valid Usage & Examples

TCP echo server and client with deadlines

Listen on an ephemeral loopback port, accept a connection, set a read deadline, and exchange data.

lora Allowed 
use coro;
use net;
use netip;
use strings;

export fn main() void = {
	let l = net::listen_at("127.0.0.1:0")!;
	let addr = net::listener_addr(&l) as netip::addr_port;
	let pl = &l;

	@scope {
		@go {
			let s = net::accept(pl)!;
			net::set_read_deadline(&s, net::after(2000));
			let buf: [64]u8 = [0...];
			let n = net::read(&s, buf[..])!;
			net::write_all(&s, buf[..n])!;
		};
		@go {
			let c = net::dial_tcp(addr)!;
			net::write_all(&c, strings::to_bytes("hello"))!;
			let buf: [64]u8 = [0...];
			let n = net::read(&c, buf[..])!;
			assert(strings::from_bytes(buf[..n]) == "hello");
		};
	}!;
}

Unix domain socket with half-close and io::read_all

Create a local Unix stream socket, close the write half from the client, and read until EOF on the server.

lora Allowed 
use fs;
use io;
use net;
use strings;

export fn main() void = {
	let path = "/tmp/lora-doc-example.sock";
	fs::remove(path) or void;
	let l = net::listen_unix(path)!;
	let c = net::dial_unix(path)!;
	let s = net::accept(&l)!;

	net::write_all(&c, strings::to_bytes("streamed payload"))!;
	net::close_write(&c)!;

	let body = io::read_all(&s, 4096)!;
	defer free(body);
	assert(strings::from_bytes(body) == "streamed payload");
}

UDP datagram exchange with packet_conn

Bind a UDP socket, send a datagram from a second socket, and inspect the received datagram metadata.

lora Allowed 
use net;
use netip;
use strings;

export fn main() void = {
	let srv = net::listen_udp(netip::parse_addr_port("127.0.0.1:0")!)!;
	let srv_addr = net::packet_addr(&srv) as netip::addr_port;

	let cli = net::dial_udp(srv_addr)!;
	net::send(&cli, strings::to_bytes("ping"))!;

	let buf: [64]u8 = [0...];
	let dg = net::receive_from(&srv, buf[..])!;
	assert(!dg.truncated && strings::from_bytes(buf[..dg.n]) == "ping");
}

Disallowed Forms & Diagnostics

Exceed UNIX_PATH_MAX or pass NUL in Unix socket path

net::unix returns void for empty paths, paths with embedded NUL bytes, or paths exceeding UNIX_PATH_MAX (103 bytes); dial_unix fails with ENAMETOOLONG.

ENAMETOOLONG: net::error with errno == rt::ENAMETOOLONG
lora Rejected 
use net;
use strings;

export fn main() void = {
	let long: [150]u8 = ['a'...];
	let c = net::dial_unix(strings::from_bytes(long[..]))!; // error: path exceeds UNIX_PATH_MAX (ENAMETOOLONG)
}
lora Allowed 
use net;

export fn main() void = {
	let u = net::unix("/tmp/app.sock") as net::unix_addr; // ok: valid path within UNIX_PATH_MAX
	assert(net::unix_path(&u) == "/tmp/app.sock");
}

Module Guide & Examples

Network connections: TCP over IPv4 and IPv6, UDP, and local (Unix) sockets, as streams, listeners and datagrams.

let l = net::listen_tcp(netip::parse_addr_port("127.0.0.1:8080")!)!; let c = net::accept(&l)!; // a conn: io::reader, writer, closer net::set_deadline(&c, net::after(5000)); io::copy(&c, &c)!; // echo, for five seconds at most

Every socket is non-blocking and waits the way its caller runs: in a coroutine it lets the others run meanwhile (on kqueue), outside one it waits for itself. A u64 bounds every read, write, accept and dial that comes after it is set: past it, the call fails with ETIMEDOUT (io::timed_out through the io interfaces), and the socket stays usable if the u64 is moved. In a coroutine whose scope is cancelled, a wait ends at once with ECANCELED.

Sockets are owners: each closes itself when it is dropped, and one that is closed or moved is closed once. Writing to a peer that has gone is an error (EPIPE), never a signal that ends the program.

TCP over IPv4 and IPv6, UDP, and local (Unix) sockets, as streams, listeners and datagrams. Every socket waits the way its caller runs: in a coroutine it lets the others run meanwhile, outside one it waits for itself. A deadline bounds every read, write, accept and dial after it is set (ETIMEDOUT, io::timed_out through the io interfaces); a cancelled coroutine's wait ends at once (ECANCELED). Sockets close themselves when dropped, and writing to a gone peer is EPIPE, never a signal.

use io;
use net;
use netip;

export fn main() void = {
	let l = net::listen_at("127.0.0.1:0")!;
	let c = net::dial(net::listener_addr(&l))!;
	let s = net::accept(&l)!;
	io::write_str(&c, "hello")!;
	net::close_write(&c)!;
	net::set_read_deadline(&s, net::after(1000));
	let got = io::read_all(&s, 100)!;
	assert(len(got) == 5);
}

A server gives each connection a coroutine of its own: @go serve(c) moves the connection c into the child, which closes it when it returns. Example: λexamples/coro_echo.lora. dial_host and lookup ask the system; dns asks the servers itself.
