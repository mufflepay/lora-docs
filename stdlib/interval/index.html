Standard Library

interval — Augmented interval tree

Module interval (lib/interval.lora) exports 16 declarations. Import with use interval;.

Overview

interval implements an augmented binary search tree (interval::tree) for closed i64 intervals [lo, hi] tagged with a u64 user ID.

Each node tracks max_hi for its subtree, enabling O(log N + K) overlap (query_overlap), point (query_point), containment (query_contained), and existence (has_overlap) queries. Deletions mark nodes as tombstones and automatically trigger compact (which iteratively rebuilds a balanced tree) once dead >= 64 && dead > n.

SymbolPurpose
new / count / is_empty / clear / finishCreate, inspect, and release an interval tree
add / remove / compactInsert [lo, hi] with tag id, tombstone-remove, or rebalance
query_overlap / query_point / query_containedReturn owned ^[]entry matching overlap, point, or containment
has_overlap / allFast boolean overlap check or dump all live entries

Valid Usage & Examples

Point, overlap, and containment queries

Insert [lo, hi] intervals and query overlapping, containing, and enclosed ranges.

lora Allowed 
use interval;

export fn main() void = {
	let it = interval::new();
	defer interval::finish(&it);

	interval::add(&it, 10, 20, 1u64)!;
	interval::add(&it, 15, 25, 2u64)!;
	interval::add(&it, 30, 40, 3u64)!;

	let pts = interval::query_point(&it, 16)!;
	defer free(pts);
	assert(len(pts) == 2z);

	let ov = interval::query_overlap(&it, 22, 32)!;
	defer free(ov);
	assert(len(ov) == 2z);

	assert(interval::has_overlap(&it, 35, 36)!);
	assert(!interval::has_overlap(&it, 26, 29)!);
}

Removing intervals and compacting tombstones

Remove an interval by (lo, hi, id) and explicitly rebalance with interval::compact.

lora Allowed 
use interval;

export fn main() void = {
	let it = interval::new();
	interval::add(&it, 1, 10, 100u64)!;
	interval::add(&it, 5, 15, 200u64)!;

	assert(interval::remove(&it, 1, 10, 100u64));
	assert(interval::count(&it) == 1z);

	interval::compact(&it)!;
	let remaining = interval::all(&it)!;
	defer free(remaining);
	assert(len(remaining) == 1z && remaining[0].id == 200u64);
}

Disallowed Forms & Diagnostics

Adding or querying an inverted interval (lo > hi)

add, query_overlap, query_contained, and has_overlap all enforce requires(lo <= hi).

Precondition: requires(lo <= hi) fails for inverted interval bounds
lora Rejected 
use interval;

export fn main() void = {
	let it = interval::new();
	interval::add(&it, 20, 10, 1u64)!; // error: violates requires(lo <= hi)
}
lora Allowed 
use interval;

export fn main() void = {
	let it = interval::new();
	interval::add(&it, 10, 20, 1u64)!; // ok: lo <= hi satisfies precondition
}

Constraints & Limits

Bounds & tags
lo, hi: i64; id: u64
Intervals are closed `[lo, hi]` with `lo <= hi`.
Auto-compaction
dead >= 64 && dead > n
`remove` triggers `compact` automatically past this threshold.
Compact sort
O(N^2) insertion sort
Incremental `add` does not self-balance; call `compact` after skewed bulk inserts.

Module Guide & Examples

Augmented interval tree for O(log N + K) overlap and point queries over [lo, hi] ranges.

let it = interval::new(); defer interval::finish(&it); interval::add(&it, 10, 20, 1u64)!; let hits = interval::query_point(&it, 15)!;

Iterative O(log N + K) overlap, point, and containment queries with balanced compaction (new, add, remove, query_point, query_overlap, query_contained, has_overlap, all, compact, count, is_empty, clear, finish).

lora 
let it = interval::new();
defer interval::finish(&it);
interval::add(&it, 10, 20, 1u64)!;
assert(interval::has_overlap(&it, 15, 25)!);
