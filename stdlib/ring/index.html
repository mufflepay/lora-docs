ring — fixed-capacity circular buffers and byte_ring

Module ring (lib/ring.lora) exports 35 declarations. Import with use ring;.

Overview

ring provides two fixed-capacity circular buffers: generic ring::ring[T] and bulk ring::byte_ring.

Both pre-allocate their backing buffer once at construction and perform O(1) push/pop without shifting elements. ring[T] forbids elements that own heap memory (@owns(T)). byte_ring uses mem::copy to handle wrap-around reads and writes in at most two contiguous copies.

Valid Usage & Examples

Bounded ring[T] with full_err and overwrite mode

Use ring::push for backpressure (ring::full_err) or ring::push_overwrite for rolling history.

lora Allowed 
use ring;

export fn main() void = {
	let r = ring::new::[int](3z)!;
	ring::push(&r, 10)!;
	ring::push(&r, 20)!;
	ring::push(&r, 30)!;
	assert(ring::push(&r, 40) is ring::full_err);

	// Overwrite evicts the oldest element (10)
	let evicted = ring::push_overwrite(&r, 40);
	assert(evicted as int == 10);
	assert(ring::pop(&r) as int == 20);
	assert(ring::pop(&r) as int == 30);
	assert(ring::pop(&r) as int == 40);
}

Bulk wrap-around I/O with byte_ring

Write, peek, search, and consume byte chunks across the ring wrap boundary.

lora Allowed 
use ring;
use strings;

export fn main() void = {
	let br = ring::bytes_new(8z)!;
	assert(ring::bytes_write(&br, strings::to_bytes("hello")) == 5z);

	let head: [3]u8 = [0...];
	assert(ring::bytes_read(&br, head[..]) == 3z);
	assert(strings::from_bytes(head[..]) == "hel");

	// Wraps around the 8-byte buffer
	assert(ring::bytes_write(&br, strings::to_bytes("world!")) == 6z);
	let pos = ring::bytes_find(&br, 'w') as usize;
	assert(pos == 2z);
}

Disallowed Forms & Diagnostics

Calling push_overwrite on a zero-capacity ring

ring::push_overwrite asserts r.max_cap > 0z because there is no slot to overwrite.

Assertion: assert(r.max_cap > 0z) aborts at runtime
lora Rejected 
use ring;

export fn main() void = {
	let r = ring::new::[int](0z)!;
	let _ = ring::push_overwrite(&r, 1); // error: asserts r.max_cap > 0z and aborts
}
lora Allowed 
use ring;

export fn main() void = {
	let r = ring::new::[int](4z)!; // ok: non-zero capacity allows overwrite
	let _ = ring::push_overwrite(&r, 1); // ok: r.max_cap > 0z
}

Constraints & Limits

Capacity
Fixed at creation
Never reallocates after `new` or `bytes_new`.
Full behavior
full_err or overwrite
`push` returns `ring::full_err`; `push_overwrite` requires `max_cap > 0z`.
Ownership
Non-owning T
`@owns(T)` is rejected at compile time for `ring[T]`.

Module Guide & Examples

Fixed-capacity circular buffers: generic ring[T] and zero-copy byte_ring.

Both types pre-allocate a fixed capacity and perform O(1) push/pop without shifting elements. Like deque[T] and map[K, V], ring[T] elements must not own heap memory.

ring[T] and byte_ring pre-allocate a fixed capacity for O(1) non-shifting push/pop, overwrite mode (push_overwrite, bytes_write_overwrite), and bulk wrap-around byte reads/writes (bytes_write, bytes_read, bytes_peek, bytes_find).

lora 
let br = ring::bytes_new(8z)!;
let _ = ring::bytes_write(&br, strings::to_bytes("hello"));
