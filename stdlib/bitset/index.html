Standard Library

bitset — dynamic bitset and Bloom filter

Module bitset (lib/bitset.lora) exports 44 declarations. Import with use bitset;.

Overview

bitset provides a compact, dynamically sized bitset backed by ^[]u64 words (with automatic impl drop) and a probabilistic bloom filter using FNV-1a + SplitMix64 double hashing.

Unused high bits in the final word are masked by tail_mask so count_ones, all, equals, and invert remain exact. Element-level set, unset, toggle, get, set_range, and clear_range carry requires(...) contracts.

Valid Usage & Examples

Dynamic bitset ranges, set algebra, and rank/select

Set bit ranges, compute set intersections/unions, and query rank and select.

lora Allowed 
use bitset;

export fn main() (void | nomem) = {
	let a = bitset::new(128z)?;
	let b = bitset::new(128z)?;
	bitset::set_range(&a, 10z, 20z);
	bitset::set(&b, 15z);
	bitset::set(&b, 100z);

	assert(bitset::count_ones(&a) == 10z);
	assert(bitset::rank(&a, 15z) == 5z);
	assert((bitset::select(&a, 0z) as usize) == 10z);

	bitset::union_with(&a, &b);
	assert(bitset::get(&a, 100z));
	assert((bitset::last_set(&a) as usize) == 100z);
}

Probabilistic Bloom filter with false-positive rate sizing

Size a Bloom filter for expected item count and false-positive rate, add keys, and test membership.

lora Allowed 
use bitset;

export fn main() (void | nomem) = {
	let bf = bitset::bloom_new(1000z, 0.01)?;
	bitset::bloom_add_str(&bf, "alice");
	bitset::bloom_add_str(&bf, "bob");

	assert(bitset::bloom_contains_str(&bf, "alice"));
	assert(bitset::bloom_contains_str(&bf, "bob"));
	assert(bitset::bloom_count_ones(&bf) > 0z);
}

Disallowed Forms & Diagnostics

Accessing a bit index >= `nbits`

set, unset, toggle, and get enforce requires(idx < b.nbits) contracts.

L1000 / CONTRACT: contract violation: `idx < b.nbits`
lora Rejected 
use bitset;

export fn main() void = {
	let b = bitset::new(64z)!;
	bitset::set(&b, 64z); // error: violates idx < b.nbits
}
lora Allowed 
use bitset;

export fn main() void = {
	let b = bitset::new(64z)!;
	bitset::resize(&b, 65z)!; // ok: grow bitset so index 64 is in bounds
	bitset::set(&b, 64z); // ok: 64z < b.nbits
}

Constraints & Limits

Index Contract
idx < b.nbits
`set`, `unset`, `toggle`, `get` require `idx < b.nbits`; `set_range`/`clear_range` require `lo <= hi && hi <= b.nbits`.
Bloom Minimum Size
64 bits, 1 hash
`bloom_with_params` clamps `nbits == 0` to `64` and `n_hashes == 0` to `1`.
Drop Cleanup
Automatic
Both `bitset` and `bloom` implement `drop` to free their backing `^[]u64`.

Module Guide & Examples

Compact dynamic bitset and Bloom filter.

Word-packed bitset with range operations (set_range, clear_range), bitwise set algebra (union_with, intersect_with, difference_with, symmetric_difference_with), next_set/next_unset, rank/select, to_bytes, and bloom probabilistic filters.
