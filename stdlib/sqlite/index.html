Standard Library

sqlite — SQLite3 driver for the sql package

Module sqlite (lib/sqlite.lora) exports 8 declarations. Import with use sqlite;.

Overview

sqlite is Lora's embedded SQLite3 driver for sql. It loads libsqlite3 dynamically at runtime via dlopen (libsqlite3.dylib, libsqlite3.so.0, libsqlite3.so), so programs that do not import sqlite incur zero extra link dependencies.

sqlite::open(path) and sqlite::open_with(cfg, lim) return a pooled sql::db[sqlite::config, sqlite::conn] compatible with all sql::* functions. sqlite::connect(path) and sqlite::connect_with(&cfg) open a single direct sqlite::conn (which implements drop and sql::link). By default, config enables foreign keys (PRAGMA foreign_keys = ON), sets a 5000 ms busy timeout, and enables WAL mode for file-backed writable databases.

Valid Usage & Examples

In-memory database with pooled sql:: operations

Open an in-memory SQLite database with sqlite::open(":memory:") and run DDL, inserts, and typed queries.

lora Allowed 
use expanse;
use sql;
use sqlite;

type item = struct { id: i64, name: str, price: f64 }

export fn main() void = {
	let db = sqlite::open(":memory:")!;
	defer sql::close(&db);

	sql::script(&db, "create table items (
		id integer primary key autoincrement,
		name text not null unique,
		price real not null);")!;

	sql::exec(&db, "insert into items (name, price) values ($1, $2)", ["pen", 1.5])!;
	let cnt = sql::scalar::[i64](&db, "select count(*) from items", [])!;
	assert(cnt == 1);

	let r = expanse::reserve(expanse::MIB)!;
	defer expanse::finish(&r);
	let rows = sql::all::[item](&db, &r, "select id, name, price from items", [])!;
	defer free(rows);
	assert(rows[0].name == "pen");
}

File-backed database with WAL and custom pool limits

Configure sqlite::config and sql::limits explicitly with sqlite::open_with for persistent storage.

lora Allowed 
use sql;
use sqlite;

export fn main() void = {
	let cfg = sqlite::config {
		path = "/tmp/lora_app.db",
		wal = true,
		foreign_keys = true,
		busy_timeout_ms = 3000,
		...
	};
	let lim = sql::limits { max_open = 4, max_idle = 2, ... };
	let db = sqlite::open_with(cfg, lim)!;
	defer sql::close(&db);

	sql::script(&db, "create table if not exists kv (k text primary key, v text)")!;
	sql::exec(&db, "insert or replace into kv (k, v) values ($1, $2)", ["version", "1"])!;
}

Direct connection and last_insert_rowid

Use sqlite::connect when you need a single connection and access to sqlite::last_insert_rowid.

lora Allowed 
use fmt;
use sql;
use sqlite;

export fn main() void = {
	let c = sqlite::connect(":memory:")!;
	defer sqlite::close(&c);

	c.script("create table logs (id integer primary key autoincrement, msg text)")!;
	c.run("insert into logs (msg) values ($1)", ["started"])!;
	let id = sqlite::last_insert_rowid(&c);
	fmt::println($"inserted rowid ${id}")!;
}

Disallowed Forms & Diagnostics

Do not expect ":memory:" pools with multiple connections to share state

Each connection opened to ":memory:" creates a separate private in-memory database; if max_open > 1 opens a second connection, it will not see tables from the first.

sql::server: no such table: t (SQLSTATE HY000)
lora Rejected 
use sql;
use sqlite;

export fn main() void = {
	let db = sqlite::open_with(
		sqlite::config { path = ":memory:", ... },
		sql::limits { max_open = 4, max_idle = 0, ... },
	)!;
	defer sql::close(&db);
	// With max_idle = 0, each query opens a fresh ":memory:" database!
	sql::script(&db, "create table t (x int)")!;
	let _ = sql::exec(&db, "insert into t values (1)", [])!; // error: sql::server (no such table: t) on fresh connection
}
lora Allowed 
use sql;
use sqlite;

export fn main() void = {
	let db = sqlite::open_with(
		sqlite::config { path = "file:memdb1?mode=memory&cache=shared", ... }, // ok: shared-cache URI shares in-memory DB across pooled connections
		sql::limits { max_open = 4, max_idle = 2, ... },
	)!;
	defer sql::close(&db);
	sql::script(&db, "create table t (x int)")!;
	sql::exec(&db, "insert into t values (1)", [])!;
}

Constraints & Limits

Dynamic library loading
`libsqlite3.dylib` / `libsqlite3.so.0` / `libsqlite3.so`
Loaded via `dlopen` on first connect; returns `sql::unsupported` if not found.
SQLite constraint mapping
`SQLITE_CONSTRAINT*` -> `sql::conflict` (`23505`)
Unique and primary key constraint violations map to `sql::conflict`; other errors map to `sql::server` (`HY000`).
Default busy timeout
5000 ms
Configured via `config.busy_timeout_ms` on connection open.
Parameter types
`void`, `bool`, `i64`, `f64`, `str`, `bytes`, `instant`, `date`, `clock`, `numeric`, `uuid`
Other `sql::value` variants return `sql::unsupported`.
  • sqlite::open(":memory:") uses sql::limits { ... } (max_idle = 2); for multi-connection concurrency on an in-memory DB, use a shared-cache URI like "file:name?mode=memory&cache=shared" or keep max_open = 1.

Module Guide & Examples
