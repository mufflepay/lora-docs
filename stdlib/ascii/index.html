Standard Library

ascii — zero-table ASCII predicates, case folding, and trimming

Module ascii (lib/ascii.lora) exports 30 declarations. Import with use ascii;.

Overview

Fast, zero-table ASCII byte (u8) predicates, numeric digit decoding, case-insensitive string comparisons, whitespace trimming, and case conversion.

Every predicate and byte transform operates directly on u8 with simple range arithmetic—no lookup tables and no locale dependence. Non-ASCII bytes (> 0x7F) pass through to_lower and to_upper unchanged.

Valid Usage & Examples

Zero-allocation header matching and digit parsing

Validate ASCII bytes, parse hex/decimal digits, and compare protocol headers case-insensitively.

lora Allowed 
use ascii;

export fn main() void = {
	assert(ascii::is_ascii_str("Content-Type"));
	assert(!ascii::is_ascii_str("café"));
	assert(ascii::eq_ignore_case("Content-Type", "content-type"));
	assert(ascii::has_prefix_ignore_case("Authorization: Bearer", "authorization:"));
	assert(ascii::has_suffix_ignore_case("README.MD", ".md"));
	assert(ascii::trim_space(" \t\nhi \r\n") == "hi");

	assert((ascii::digit_value('9') as u8) == 9u8);
	assert((ascii::hex_value('F') as u8) == 15u8);
	assert(ascii::hex_value('g') is void);
}

In-place buffer casing vs allocating string casing

Mutate a []u8 buffer in place with zero allocations, or allocate an owned ^str with to_lower_str / to_upper_str.

lora Allowed 
use ascii;
use strings;

export fn main() (void | nomem) = {
	let buf: [5]u8 = ['H', 'e', 'L', 'L', 'o'];
	ascii::to_lower_in_place(buf[..]);
	assert(strings::from_bytes(buf[..]) == "hello");

	let up = ascii::to_upper_str("HeLLo 123!")?;
	defer free(up);
	assert(up == "HELLO 123!");
}

Disallowed Forms & Diagnostics

Unwrapping hex_value without handling void

digit_value and hex_value return ?u8 ((u8 | void)). Always check is u8 / match before using the value on untrusted input.

L0200: type mismatch: expected u8, got (u8 | void)
lora Rejected 
use ascii;

export fn main() void = {
	let v: u8 = ascii::hex_value('Z'); // error: hex_value returns (u8 | void), not u8
}
lora Allowed 
use ascii;

export fn main() void = {
	let v = match (ascii::hex_value('Z')) { // ok: handles void variant via match
		let d: u8 => d,
		void => 0u8,
	};
	assert(v == 0u8);
}

Constraints & Limits

Character set
7-bit ASCII (0x00..0x7F)
`is_space` covers space, `\t`, `\n`, `\r`, `0x0B`, `0x0C`; non-ASCII bytes are untouched by casing.
Tables & allocation
Zero tables
Only `to_lower_str` and `to_upper_str` allocate (`^str | nomem`); all other functions are zero-alloc.
