rt — runtime (used by other modules)

Import with use rt;.

Overview

rt is the Lora runtime (runtime/). It provides program startup (_main calling @init, user main, and @fini), libc system bindings, memory allocation (malloc, realloc, free_, ensure) with optional LORA_LEAKS / LORA_LEAKS=guard tracking, runtime type metadata (typeinfo, type_kind, any), coroutine context switching, drop dispatch, errno, and abort diagnostics.

Application code rarely calls rt directly except for:

  • Inspecting rt::errno constants (e.g. e.errno == rt::EADDRINUSE) wrapped inside stdlib errors like io::error, fs::error, or net::error.
  • Reading heap counters with rt::heap_stats() -> rt::alloc_stats.
  • Registering a custom global allocator via rt::set_global_allocator / rt::reset_global_allocator (marked @unsafe).

Valid Usage & Examples

Compare wrapped errno values against rt constants

Standard library modules wrap rt::errno inside their own error structs; compare e.errno against rt::ENOENT, rt::EADDRINUSE, etc.

lora Allowed 
use fmt;
use fs;
use rt;

export fn main() void = {
	match (fs::open("/nonexistent/lora/path")) {
		let f: fs::file => void,
		let e: fs::error => {
			if (e.errno == rt::ENOENT) {
				fmt::println($"missing file: ${rt::errno_name(e.errno)}")!;
			}
		},
		nomem => abort("nomem"),
	}
}

Inspect global heap allocation statistics

Snapshot rt::heap_stats() before and after an operation to measure total allocations, frees, and allocated bytes.

lora Allowed 
use fmt;
use rt;
use strings;

export fn main() void = {
	let before = rt::heap_stats();
	let s = strings::clone("runtime stats")!;
	free(s);
	let after = rt::heap_stats();
	fmt::println($"allocs=${after.allocs - before.allocs} frees=${after.frees - before.frees}")!;
}

Disallowed Forms & Diagnostics

Do not call @unsafe rt allocator functions outside an unsafe block

rt::malloc, rt::realloc, rt::set_global_allocator, and rt::drop_owned are @unsafe and cannot be called from safe Lora code.

E0501: cannot call @unsafe function outside an unsafe block
lora Rejected 
use rt;

export fn main() void = {
	// Compile error: calling @unsafe function `rt::malloc` outside `unsafe`
	let p = rt::malloc(64);
	let _ = p;
}
lora Allowed 
use rt;

export fn main() void = {
	let p = unsafe { rt::malloc(64) }; // ok: @unsafe allocator call inside unsafe block
	if (p != null) {
		unsafe { rt::free_(p) };
	}
}

Constraints & Limits

Leak & guard diagnostics
`LORA_LEAKS=1` / `LORA_LEAKS=guard`
When unset, overhead is a single global flag test per allocation; `guard` maps `PROT_NONE` guard pages via `mmap`.
Platform backends
Darwin (`+darwin`) and Linux (`+linux/+x86_64`, `+linux/+aarch64`)
Process spawning (`posix_spawn`) and signal/kqueue helpers are currently macOS-only.
Variadic libc ABI rule
Declare C variadics with `...`
On Darwin ARM64, variadic libc functions like `open(path, flags, ...)` must use `...` so `mode` is passed on the stack.
  • rt::errno is never returned directly by stdlib APIs; it is always embedded inside module error types (e.g. fs::error, io::error, net::error).

Module Guide & Examples

The rt module is the runtime contract: open, close, read, write, malloc/free_, memcpy/memmove/memset, strcmp, exit and the error union. Documented in docs/runtime.md.
