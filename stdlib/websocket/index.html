Standard Library

websocket — RFC 6455 WebSocket protocol

Module websocket (lib/websocket.lora) exports 39 declarations. Import with use websocket;.

Overview

websocket implements RFC 6455 WebSocket handshake key helpers (generate_key, accept_key, verify_accept), frame encoding/decoding (encode_frame, encode_frame_random_mask, decode_frame, read_frame, write_frame), close payload encoding/decoding (encode_close_payload, decode_close_payload), and fragmented message reassembly (assembler, feed_frame).

It enforces RSV bit checks, control frame length/fragmentation rules, minimal length encodings, and configurable mask_policy (any, require_masked, require_unmasked).

Valid Usage & Examples

Compute and verify RFC 6455 handshake keys

Generate a client Sec-WebSocket-Key, compute the server Sec-WebSocket-Accept digest, and verify it.

lora Allowed 
use websocket;

export fn main() void = {
	let key = websocket::generate_key()!;
	defer free(key);
	let accept = websocket::accept_key(key)!;
	defer free(accept);
	assert(websocket::verify_accept(key, accept)!);
}

Encode, mask, read, and reassemble fragmented frames

Write masked/unmasked frames to an io::buffer, read them back with mask_policy, and reassemble fragmented messages while handling interleaved control frames.

lora Allowed 
use io;
use strings;
use websocket;

export fn main() void = {
	let a = websocket::new_assembler();
	let wire: ^[]u8 = [];
	defer free(wire);
	websocket::encode_frame(&wire, websocket::opcode::text, strings::to_bytes("Hel"), false)!;
	websocket::encode_frame(&wire, websocket::opcode::continuation, strings::to_bytes("lo!"), true)!;

	let off = 0z;
	for (off < len(wire)) {
		let (f, n) = websocket::decode_frame(wire[off..])!;
		off += n;
		match (websocket::feed_frame(&a, &f)!) {
			let msg: websocket::message => assert(strings::from_bytes(msg.data[..]) == "Hello!"),
			void => void,
		}
	}
}

Disallowed Forms & Diagnostics

Fragment a control frame (ping/pong/close) or use reserved close codes

RFC 6455 forbids fragmented control frames (fin=false) and wire-encoding pseudo-codes like CLOSE_NO_STATUS (1005).

websocket::protocol_error: websocket protocol error: invalid close status code
lora Rejected 
use websocket;

export fn main() void = {
	let cp = websocket::encode_close_payload(websocket::CLOSE_NO_STATUS, "")!; // error: reserved pseudo-code 1005 cannot be sent on the wire
}
lora Allowed 
use websocket;

export fn main() void = {
	let cp = websocket::encode_close_payload(websocket::CLOSE_NORMAL, "bye")!; // ok: standard close code 1000
	defer free(cp);
}

Constraints & Limits

Default max_message
16 MiB
Default payload/message cap in decode_frame, read_frame, and new_assembler.
Control frame payload
125 bytes max
RFC 6455 limits ping/pong/close payloads to 125 bytes.

decode_frame and read_frame enforce RFC 6455 invariants: zero RSV bits, valid opcodes, non-fragmented control frames with payloads ≤ 125 bytes, minimal length encodings, and bounded payload sizes. feed_frame reassembles fragmented text/binary messages, passes over interleaved control frames, and validates UTF-8 on completed text messages.
