trace — W3C Trace Context propagation and lightweight span recording

Module trace (lib/trace.lora) exports 25 declarations. Import with use trace;.

Overview

W3C Trace Context (traceparent / tracestate) propagation and lightweight monotonic span recording.

trace generates cryptographically random non-zero 16-byte trace IDs and 8-byte span IDs via rt::getentropy, parses and formats W3C traceparent (00-<32hex>-<16hex>-<2hex>) and tracestate headers, and records spans timed with CLOCK_MONOTONIC.

Valid Usage & Examples

Propagating W3C traceparent and tracestate headers

Create a root context, format its traceparent, parse it back, and update tracestate.

lora Allowed 
use trace;

export fn main() void = {
	let root = trace::new_root(true);
	assert(trace::is_sampled(&root));
	let hdr = trace::format_traceparent(&root)!;
	let parsed = trace::parse_traceparent(hdr)!;
	assert(trace::is_sampled(&parsed));

	let ts = trace::parse_tracestate("rojo=00f067aa,congo=t61rcWkgMzE")!;
	let updated = trace::tracestate_set(ts, "congo", "newval")!;
	assert(trace::tracestate_get(updated, "congo") as str == "newval");
}

Recording parent and child spans

Start a root span, create a child span, attach attributes and events, and compute elapsed nanoseconds.

lora Allowed 
use trace;

export fn main() void = {
	let tc = trace::new_root(true);
	let parent = trace::start_span("http.request", &tc)!;
	trace::set_attr(&parent, "http.method", "GET")!;

	let child = trace::start_child_span("db.query", &parent)!;
	trace::add_event(&child, "cache.miss")!;
	trace::set_status(&child, trace::span_status::ok);
	trace::end_span(&child);
	trace::end_span(&parent);

	assert(child.has_parent);
	assert(trace::duration_ns(&child) >= 0i64);
}

Disallowed Forms & Diagnostics

Parsing an all-zero trace ID or uppercase traceparent

W3C Trace Context requires lowercase hex, version != ff, and non-zero trace_id and span_id; invalid headers return trace::bad_trace.

E_RUNTIME_UNWRAP: invalid W3C trace context
lora Rejected 
use trace;

export fn main() void = {
	let _ = trace::parse_traceparent("00-00000000000000000000000000000000-00f067aa0ba902b7-01")!; // error: all-zero trace_id returns trace::bad_trace
}
lora Allowed 
use trace;

export fn main() void = {
	let res = trace::parse_traceparent("00-00000000000000000000000000000000-00f067aa0ba902b7-01"); // ok: inspects error union instead of force-unwrapping
	assert(res is trace::bad_trace);
}

Constraints & Limits

traceparent length
Exactly 55 bytes
Strict W3C format 00-<32hex>-<16hex>-<2hex> with lowercase hex, version != 0xff, and non-zero IDs.
Span clock
CLOCK_MONOTONIC (ns)
duration_ns returns 0 if end_span has not been called yet.
