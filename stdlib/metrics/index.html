metrics — Counters, gauges, histograms, and Prometheus exposition

Module metrics (lib/metrics.lora) exports 28 declarations. Import with use metrics;.

Overview

Thread-safe observability metrics (counters, gauges, histograms with quantile estimation) and Prometheus text exposition formatting.

Every metric validates its name against Prometheus naming rules ([a-zA-Z_:][a-zA-Z0-9_:]*), returning bad_metric on invalid names or non-finite/non-increasing histogram bucket bounds. All metric updates and reads are synchronized with thread::mutex.

Valid Usage & Examples

Tracking requests and formatting Prometheus exposition

Create a counter and gauge, update them, and render Prometheus text format with prometheus_counter and prometheus_gauge.

lora Allowed 
use metrics;
use strings;

export fn main() void = {
	let reqs = metrics::new_counter("http_requests_total", "Total HTTP requests")!;
	metrics::counter_inc(&reqs, 3u64);
	assert(metrics::counter_get(&reqs) == 3u64);

	let active = metrics::new_gauge("active_conns", "Active connections")!;
	metrics::gauge_inc(&active);
	metrics::gauge_add(&active, 4.0);
	assert(metrics::gauge_get(&active) == 5.0);

	let text = metrics::prometheus_counter(&reqs)!;
	assert(strings::contains_str(text, "# TYPE http_requests_total counter"));
	assert(strings::contains_str(text, "http_requests_total 3"));
}

Observing latencies in a histogram and estimating quantiles

Use metrics::DEFAULT_BUCKETS, record observations (NaN is ignored), and estimate p95 with histogram_quantile.

lora Allowed 
use metrics;

export fn main() void = {
	let lat = metrics::new_histogram("req_duration_seconds", metrics::DEFAULT_BUCKETS[..], "Latency")!;
	metrics::histogram_observe(&lat, 0.004);
	metrics::histogram_observe(&lat, 0.020);
	metrics::histogram_observe(&lat, 0.080);

	assert(metrics::histogram_count(&lat) == 3u64);
	let p95 = metrics::histogram_quantile(&lat, 0.95);
	assert(p95 > 0.0);
}

Disallowed Forms & Diagnostics

Using hyphens in metric names or unsorted histogram bounds

Prometheus metric names only allow ASCII letters, digits, _, and :, and histogram bounds must be finite and strictly increasing.

E_RUNTIME_UNWRAP: invalid metric: invalid metric name
lora Rejected 
use metrics;

export fn main() void = {
	let _ = metrics::new_counter("http-requests")!; // error: hyphen is not allowed in metric names
}
lora Allowed 
use metrics;

export fn main() void = {
	let c = metrics::new_counter("http_requests"); // ok: uses underscore instead of hyphen
	assert(c is metrics::counter);
}

Constraints & Limits

Metric name charset
[a-zA-Z_:][a-zA-Z0-9_:]*
Empty names or disallowed characters return bad_metric.
Histogram bounds
Strictly increasing finite f64
NaN, +/-Inf, or non-increasing bounds return bad_metric; NaN observations are silently ignored.
