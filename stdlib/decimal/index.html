decimal — 128-bit exact base-10 arithmetic

Module decimal (lib/decimal.lora) exports 41 declarations. Import with use decimal;.

Overview

decimal provides zero-allocation 128-bit exact base-10 arithmetic supporting up to MAX_SCALE = 38 significant decimal digits (lo: u64, hi: u64, scale: u8, neg: bool).

It avoids binary floating-point rounding errors (0.1 + 0.2 == 0.3 exactly), supports 6 rounding modes (HALF_EVEN, HALF_UP, HALF_DOWN, FLOOR, CEIL, TRUNC), scientific notation parsing, and implements encoding::text_encoder and encoding::text_decoder.

Valid Usage & Examples

Exact financial arithmetic without binary float drift

Verify 0.1 + 0.2 == 0.3 and compute exact tax/line-item totals.

lora Allowed 
use decimal;

export fn main() (void | decimal::error) = {
	let a = decimal::parse("0.1")?;
	let b = decimal::parse("0.2")?;
	let sum = decimal::add(a, b)?;
	assert(decimal::eq(sum, decimal::parse("0.3")?));

	let price = decimal::parse("19.99")?;
	let qty = decimal::from_i64(3);
	let total = decimal::mul(price, qty)?;
	assert(decimal::eq(total, decimal::parse("59.97")?));
}

Division with explicit scale and rounding modes

Compare HALF_EVEN (banker's rounding) and HALF_UP, and format into a stack buffer with zero heap allocation.

lora Allowed 
use decimal;

export fn main() (void | decimal::error) = {
	let v1 = decimal::parse("2.5")?;
	let v2 = decimal::parse("3.5")?;
	assert(decimal::eq(decimal::round(v1, 0, decimal::rounding::HALF_EVEN)?, decimal::from_i64(2)));
	assert(decimal::eq(decimal::round(v2, 0, decimal::rounding::HALF_EVEN)?, decimal::from_i64(4)));
	assert(decimal::eq(decimal::round(v1, 0, decimal::rounding::HALF_UP)?, decimal::from_i64(3)));

	let third = decimal::div(decimal::one(), decimal::from_i64(3), 4, decimal::rounding::HALF_EVEN)?;
	let buf: [48]u8 = [0...];
	assert(decimal::format_into(third, buf[..]) == "0.3333");
}

Scientific notation, 128-bit range, and `encoding` traits

Parse scientific notation, normalize trailing zeros, and encode/decode via encoding::text_encoder/text_decoder.

lora Allowed 
use decimal;
use encoding;

export fn main() (void | decimal::error | encoding::invalid | nomem) = {
	let sci = decimal::parse("1.25e-2")?;
	assert(decimal::eq(sci, decimal::parse("0.0125")?));

	let dec = decimal::zero();
	dec.decode_text("-42.75")?;
	let out: ^[]u8 = [];
	defer free(out);
	dec.encode_text(&out)?;
	assert(len(out) == 6z);
}

Disallowed Forms & Diagnostics

Passing a buffer smaller than 48 bytes to `format_into`

format_into enforces requires(len(buf) >= 48) to guarantee room for sign, 38 digits, decimal point, and leading 0..

L1000 / CONTRACT: contract violation: `len(buf) >= 48`
lora Rejected 
use decimal;

export fn main() void = {
	let d = decimal::one();
	let small: [16]u8 = [0...];
	let s = decimal::format_into(d, small[..]); // error: violates len(buf) >= 48
}
lora Allowed 
use decimal;

export fn main() void = {
	let d = decimal::one();
	let buf: [48]u8 = [0...]; // ok: buffer satisfies len(buf) >= 48
	let s = decimal::format_into(d, buf[..]); // ok: formats into >= 48-byte buffer
	assert(s == "1");
}
