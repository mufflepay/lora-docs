Standard Library

pg — PostgreSQL, spoken natively: the version 3 wire protocol, written in

Module pg (lib/pg.lora) exports 154 declarations. Import with use pg;.

Overview

pg is Lora's native PostgreSQL wire-protocol v3 driver, supporting SCRAM-SHA-256 (and -PLUS channel binding), MD5, cleartext, and trust authentication, TLS (sslmode=disable|allow|prefer|require|verify_ca|verify_full), connection pooling via sql::db[pg::config, pg::conn], prepared statement caching, COPY IN/OUT, LISTEN/NOTIFY, pipelining, Large Objects, and logical replication (pgoutput).

Use pg::open(url, lim) for a thread-safe pg::db pool compatible with all sql::* functions and @sql, or pg::connect(url) for a single unpooled pg::conn (which implements drop and can also be closed with pg::close).

Valid Usage & Examples

Pooled PostgreSQL queries with sql::db

Open a pg::db pool from a connection URL and execute parameterized queries via sql::exec and sql::scalar.

lora Allowed 
use fmt;
use pg;
use sql;

export fn main() void = {
	let db = pg::open(
		"postgres://lora_scram:scram-pw@127.0.0.1:54329/lora_test?sslmode=disable",
		sql::limits { max_open = 8, max_idle = 2, ... },
	)!;
	defer sql::close(&db);

	sql::exec(&db, "create temp table if not exists notes (id int8 generated always as identity, body text)", [])!;
	sql::exec(&db, "insert into notes (body) values ($1)", ["hello from lora"])!;
	let n = sql::scalar::[i64](&db, "select count(*) from notes", [])!;
	fmt::println($"notes count: ${n}")!;
}

Pipelined queries in a single round trip

Batch multiple parameterized statements with pg::exec_pipeline or stream individual results with pg::send_pipeline and pg::next_result.

lora Allowed 
use pg;
use sql;

export fn main() void = {
	let c = pg::connect("postgres://lora_scram:scram-pw@127.0.0.1:54329/lora_test?sslmode=disable")!;
	defer pg::close(&c);

	let changed: [2]u64 = [0...];
	pg::exec_pipeline(&c, [
		sql::statement { text = "create temp table p_items (id int4 primary key, label text)" },
		sql::statement { text = "insert into p_items values ($1, $2)", args = [1i64, "alpha"] },
	], changed[..])!;
	assert(changed[1] == 1);
}

Asynchronous LISTEN / NOTIFY and Large Objects

Subscribe to notification channels with pg::listen / pg::wait, and stream binary blobs via PostgreSQL Large Objects.

lora Allowed 
use fmt;
use pg;

export fn main() void = {
	let c = pg::connect("postgres://lora_scram:scram-pw@127.0.0.1:54329/lora_test?sslmode=disable")!;
	defer pg::close(&c);

	pg::listen(&c, "events")!;
	pg::notify(&c, "events", "job_done")!;
	let note = pg::wait(&c)!;
	fmt::println($"channel=${note.channel} payload=${note.payload}")!;
	pg::unlisten(&c, "events")!;

	pg::begin(&c)!;
	let oid = pg::lo_create(&c)!;
	let lo = pg::lo_open(&c, oid, pg::lo_mode::read_write)!;
	let payload: [4]u8 = [0x01u8, 0x02, 0x03, 0x04];
	pg::lo_write(&c, &lo, payload[..])!;
	pg::lo_close(&c, &lo)!;
	pg::commit(&c)!;
	pg::lo_unlink(&c, oid)!;
}

Disallowed Forms & Diagnostics

Do not keep str views from pg::values across pg::next calls

String and byte values returned by pg::values borrow the connection receive buffer and are invalidated on the next pg::next or pg::finish.

dangling_view: pg::values text/bytes borrow the connection buffer until the next read or finish
lora Rejected 
use pg;
use sql;

export fn main() void = {
	let c = pg::connect("postgres://localhost/lora_test?sslmode=disable")!;
	defer pg::close(&c);
	let r = pg::query(&c, "select 'hello'::text", [])!;
	let saved: str = "";
	match (pg::next(&c, &r)!) {
		let row: pg::row => {
			let vals: [1]sql::value = [void];
			saved = pg::values(row, vals[..])![0] as str; // error: borrows connection wire buffer invalidated on pg::finish
		},
		done => void,
	}
	pg::finish(&c, &r)!;
	// `saved` now points into reused/freed buffer memory
}
lora Allowed 
use pg;
use sql;
use strings;

export fn main() void = {
	let c = pg::connect("postgres://localhost/lora_test?sslmode=disable")!;
	defer pg::close(&c);
	let r = pg::query(&c, "select 'hello'::text", [])!;
	let saved: ^str = strings::clone("")!;
	defer free(saved);
	match (pg::next(&c, &r)!) {
		let row: pg::row => {
			let vals: [1]sql::value = [void];
			let s = pg::values(row, vals[..])![0] as str;
			free(saved);
			saved = strings::clone(s)!; // ok: clones borrowed view into owned heap string
		},
		done => void,
	}
	pg::finish(&c, &r)!;
}

Constraints & Limits

COPY chunk size
64 KiB (`COPY_CHUNK = 1 << 16`)
Internal buffer chunking for `pg::copy_row` / `COPY IN` streaming.
Authentication
SCRAM-SHA-256(-PLUS), MD5, cleartext, trust
SCRAM-SHA-256-PLUS binds to TLS server certificate when `channel_binding` is `prefer` or `require`.
URL & PG* env defaults
`PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`, `PGDATABASE`, `PGSSLMODE`, ...
`pg::defaults()` reads standard libpq environment variables before falling back to `/tmp`, port `5432`, user `postgres`.
OID constants
Built-in scalars, arrays, ranges, multiranges, geometry
Includes `INT8`, `TEXT`, `UUID`, `JSONB`, `NUMERIC`, `TIMESTAMPTZ`, `*_ARRAY`, `INT4RANGE`, `TSTZRANGE`, etc.
  • pg::connect returns a single pg::conn that is not safe for concurrent use by multiple coroutines; use pg::open (pg::db) for concurrent workloads.
  • Replication connections (replication=database) only run replication commands and simple scripts, not parameterized extended queries.

Module Guide & Examples

PostgreSQL, spoken natively: the version 3 wire protocol, written in Lora, with no C library. It logs in with SCRAM-SHA-256, MD5 or a password, prepares each query once per connection and caches it, sends parameters and reads results in PostgreSQL's binary forms, and does COPY, LISTEN and NOTIFY, and cancelling.

Programs use it through sql (sql::db is a pool of pg::conn); pg's own functions are the driver's, and work on one connection:

let c = pg::connect("postgres://app:secret@localhost/shop")?; defer pg::close(&c); let rows = pg::query(&c, "select id, name from customers where id = $1", [7i64])?; for (true) { let r = match (pg::next(&c, &rows)?) { done => break, let r: pg::row => r, }; let v: [2]sql::value = [void...]; let (id, name) = ...pg::values(r, v[..])?...; };

In a coroutine, waiting for the server lets others run; outside one, it waits. Over TCP it asks for TLS 1.3 (tls), as sslmode says.
