utf8 — UTF-8 validation, decoding, encoding

Module utf8 (lib/utf8.lora) exports 8 declarations. Import with use utf8;.

Overview

UTF-8 validation, scalar checks, streaming boundary inspection, and codepoint encoding/decoding.

utf8 treats invalid UTF-8 sequences gracefully during decoding by yielding U+FFFD with width 1, while validate and valid strictly enforce Unicode scalar value rules (rejecting surrogates 0xD800..0xDFFF, overlong encodings, and values above 0x10FFFF).

Valid Usage & Examples

Validating and streaming runes with full_rune and decode_rune

Check whether a partial byte buffer contains a complete UTF-8 rune before decoding.

lora Allowed 
use utf8;

export fn main() void = {
	assert(utf8::validate("Hello, 世界 🚀"));
	assert(utf8::count("Hello, 世界 🚀") == 11z);

	let rocket: [4]u8 = [0xF0, 0x9F, 0x9A, 0x80];
	assert(!utf8::full_rune(rocket[..3]));
	assert(utf8::full_rune(rocket[..]));

	let (r, w, ok) = utf8::decode_rune(rocket[..]);
	assert(ok && w == 4z && r == '🚀');
}

Decoding to runes and encoding back to UTF-8 bytes

Decode a string into ^[]rune, transform or inspect codepoints, and encode back with encode or encode_rune.

lora Allowed 
use strings;
use utf8;

export fn main() (void | nomem) = {
	let rs = utf8::decode("café")?;
	defer free(rs);
	assert(len(rs) == 4z && rs[3] == 'é');

	let bytes = utf8::encode(rs[..])?;
	defer free(bytes);
	assert(strings::from_bytes(bytes[..]) == "café");

	let scratch: [4]u8 = [0...];
	let n = utf8::encode_rune(scratch[..], 0z, '世');
	assert(n == 3z);
}

Disallowed Forms & Diagnostics

Treating decode_rune as returning an error union

decode_rune never returns an error union; it returns (rune, usize, bool). Always check .2 (validity) rather than using ? or !.

L0200: cannot unwrap non-error/non-optional type (rune, usize, bool)
lora Rejected 
use utf8;

export fn main() void = {
	let bad: [1]u8 = [0xFF];
	let (r, w, ok) = utf8::decode_rune(bad[..])!; // error: decode_rune returns a tuple, not an error union
}
lora Allowed 
use utf8;

export fn main() void = {
	let bad: [1]u8 = [0xFF];
	let (r, w, ok) = utf8::decode_rune(bad[..]); // ok: unpacks (rune, usize, bool) directly
	assert(!ok && w == 1z && @u32(r) == 0xFFFD);
}

Constraints & Limits

Scalar range
0x0..0xD7FF, 0xE000..0x10FFFF
Surrogate codepoints and values above `0x10FFFF` are rejected by `valid` and `validate`.
Replacement behavior
U+FFFD (width 1)
Malformed or truncated sequences yield `U+FFFD` with width `1` (`0` for empty input).
encode_rune capacity
Up to 4 bytes
Caller must ensure `b[pos..]` has enough room for the encoded rune (max 4 bytes).
