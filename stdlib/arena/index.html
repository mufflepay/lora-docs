arena — Growable chunked bump allocator

Module arena (lib/arena.lora) exports 15 declarations. Import with use arena;.

Overview

arena is a growable chunked heap bump allocator. It allocates variable-sized objects, slices, and strings out of linked heap chunks (^[]u8) whose addresses never move on growth, and frees or resets everything at once. Implements drop via finish.

Valid Usage & Examples

Allocating strings, structs, and slices in an arena

All pointers and slices returned by arena remain valid until reset, finish, or drop.

lora Allowed 
use arena;

type pair = struct { a: u64, b: u64 }

export fn main() void = {
	let a = arena::with_chunk_size(128);
	defer arena::finish(&a);

	let s = arena::copy_str(&a, "lora arena")!;
	assert(s == "lora arena");
	let p = arena::push(&a, pair { a = 11, b = 22 })!;
	assert(p.a == 11);
	let sl = arena::alloc_slice::[u32](&a, 4)!;
	sl[0] = 7;

	assert(sl[0] == 7);
	assert(arena::allocated(&a) >= arena::used(&a));
}

Resetting an arena to reuse chunks across passes

arena::reset resets all chunk cursors to 0 without freeing the backing buffers, avoiding repeated heap allocations.

lora Allowed 
use arena;

export fn main() void = {
	let a = arena::new();
	defer arena::finish(&a);

	for (let pass = 0; pass < 3; pass += 1) {
		let big = arena::alloc_bytes(&a, 8192, 16)!;
		assert(len(big) == 8192 && @uintptr(&big[0]) % 16 == 0);
		arena::reset(&a);
		assert(arena::used(&a) == 0 && arena::chunk_count(&a) >= 1);
	}
}

Disallowed Forms & Diagnostics

Pushing or allocating owning types in an arena

Because arena::reset and arena::finish free chunks without running element destructors, push and alloc_slice reject @owns(T) at compile time.

Compile error: An arena frees chunks without dropping elements, so T cannot own memory
lora Rejected 
use arena;
use strings;

export fn main() void = {
	let a = arena::new();
	let owned = strings::concat("hello", " world")!;
	let p = arena::push(&a, owned)!; // error: arena::push rejects @owns(T)
}

Copy string contents into the arena with arena::copy_str instead of storing ^str.

lora Allowed 
use arena;

export fn main() void = {
	let a = arena::new();
	let s = arena::copy_str(&a, "hello world")!; // ok: copies string bytes into arena as borrowed str
	assert(s == "hello world");
}

Constraints & Limits

Chunk size
4096 B default (64 B min)
with_chunk_size clamps values below 64 to 64; automatic chunk growth caps at MAX_AUTO_CHUNK (1 MiB).
Oversized allocations
Dedicated chunk
Requests larger than the scaled chunk size allocate a dedicated chunk of size + alignment.
alloc_bytes alignment
Power of 2 > 0
Enforced via requires(alignment > 0z && (alignment & (alignment - 1z)) == 0z).

Module Guide & Examples

Growable chunked bump allocator.

Allocates variable-sized objects, slices, and strings out of linked heap chunks that never move once allocated, and frees or resets all of them in one operation. Values pushed into an arena must not own heap memory.

let a = arena::new(); defer arena::finish(&a); let s = arena::copy_str(&a, "hello")!; let p = arena::push(&a, 42)!;

Chunked bump allocator whose chunks never move once allocated (new, with_chunk_size, alloc_bytes, alloc_slice, push, copy_bytes, copy_str, reset, used, allocated, chunk_count, finish).

lora 
let a = arena::new();
defer arena::finish(&a);
let s = arena::copy_str(&a, "hello")!;
