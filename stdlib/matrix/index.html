matrix — Dense f64 linear algebra

Module matrix (lib/matrix.lora) exports 24 declarations. Import with use matrix;.

Overview

matrix implements dense row-major f64 linear algebra: construction, element-wise arithmetic, transposition, matrix/vector multiplication, trace, overflow-safe Frobenius norm, LU decomposition with partial pivoting, linear system solving, matrix inversion, and Cholesky factorization.

Matrix owns a heap-allocated ^[]f64 buffer of length rows * cols. Dimension mismatches, out-of-bounds indices, singular matrices, NaNs in LU, and non-positive-definite matrices in Cholesky return Matrix_Error.

Valid Usage & Examples

LU decomposition, linear solving, and matrix inversion

Factorize a square matrix once with lu, solve multiple right-hand sides with lu_solve, and verify A * A^-1 == I.

lora Allowed 
use matrix;
use math;

export fn main() (void | matrix::Matrix_Error | nomem) = {
	let a_data: [4]f64 = [4.0, 7.0, 2.0, 6.0];
	let a = matrix::from_slice(2z, 2z, a_data[..])?;

	assert(math::fabs(matrix::det(&a)? - 10.0) < 1e-9);

	let fac = matrix::lu(&a)?;

	let b: [2]f64 = [1.0, 0.0];
	let x = matrix::lu_solve(&fac, b[..])?;
	defer free(x);
	assert(math::fabs(x[0] - 0.6) < 1e-9 && math::fabs(x[1] + 0.2) < 1e-9);

	let ainv = matrix::inv(&a)?;
	let prod = matrix::mul(&a, &ainv)?;
	assert(math::fabs(matrix::get(&prod, 0z, 0z)? - 1.0) < 1e-9);
}

Cholesky factorization of symmetric positive-definite matrices

Compute lower-triangular L such that A = L * L^T and verify reconstruction.

lora Allowed 
use matrix;
use math;

export fn main() (void | matrix::Matrix_Error | nomem) = {
	let spd_data: [9]f64 = [
		4.0, 12.0, -16.0,
		12.0, 37.0, -43.0,
		-16.0, -43.0, 98.0,
	];
	let spd = matrix::from_slice(3z, 3z, spd_data[..])?;

	let l = matrix::cholesky(&spd)?;
	let lt = matrix::transpose(&l)?;
	let recon = matrix::mul(&l, &lt)?;

	for (let i = 0z; i < 9z; i += 1z) {
		assert(math::fabs(recon.data[i] - spd.data[i]) < 1e-9);
	}
}

Disallowed Forms & Diagnostics

Inverting a singular matrix without handling `Matrix_Error`

matrix::inv returns (Matrix | Matrix_Error | nomem) and rejects singular matrices.

L0301: cannot assign `(matrix::Matrix | matrix::Matrix_Error | nomem)` to `matrix::Matrix`
lora Rejected 
use matrix;

export fn main() void = {
	let d: [4]f64 = [1.0, 2.0, 2.0, 4.0];
	let m = matrix::from_slice(2z, 2z, d[..])!;
	let inv_m: matrix::Matrix = matrix::inv(&m); // error: unhandled Matrix_Error | nomem
}
lora Allowed 
use matrix;

export fn main() void = {
	let d: [4]f64 = [1.0, 2.0, 2.0, 4.0];
	let m = matrix::from_slice(2z, 2z, d[..])!;
	defer free(m.data);
	assert(matrix::inv(&m) is matrix::Matrix_Error); // ok: check for Matrix_Error
}

Constraints & Limits

Minimum Dimensions
rows >= 1, cols >= 1
`zeros`, `identity`, and `from_slice` return `Matrix_Error` for zero dimensions.
Allocation Overflow Guard
rows * cols <= (~0z / 8z)
Prevents `usize` byte-size overflow before allocating `^[]f64`.
Cholesky Requirement
Symmetric Positive-Definite
Returns `Matrix_Error` if any diagonal pivot `<= 0.0` or `NaN`.
