Lora Roadmap

Implemented features, stdlib buildout milestones, and future compiler targets (docs/roadmap.md).

A feature and stdlib guideline distilled from the C3, Zenc and Cangjie documentation tables of contents the project follows. Each item is classified: have, partial, or new (original compiler work — including bitstructs/vectors, which upstream lorac never had). The guiding constraints are the project goals: fast compilation, full C ABI, self-hosted stdlib.

Concurrency

AreaStatusNotes
Lightweight and safe coroutineshavecoro: Go-style green threads on an M:N work-stealing scheduler (coroutines migrate between worker threads), kqueue non-blocking I/O, timers, buffered and unbuffered chan[T], select, wait groups, structured @all/@first/@scope with cancellation and deadlines, coro::serial, blocking(); thread: pthreads, mutexes, condvars, atomics
• Cooperative Multitasking: Unlike operating system threads—which are preemptively managed and forced to switch by the OS—coroutines yield control voluntarily.
• Lightweight Concurrency: Coroutines use far less memory and CPU overhead than OS threads, allowing thousands to run concurrently on a single or small pool of threads.
• Non-Blocking I/O: They let you write sequential-looking code for asynchronous operations (like network or database calls) without blocking the main execution thread.

Stdlib (lib/) buildout

Priority order, smallest dependencies first:

  1. math — abs/min/max, sqrt/pow/trig via libm (C interop already proven)
  2. strings — Unicode codepoint iteration, replace, repeat, to-lower/upper
  3. sort — generic introsort + binary search, done 2026-10-27
  4. hash — FNV-1a (exists in compiler sources, expose to users)
  5. encoding::utf8 — validate/decode/encode
  6. encoding::json — needs tagged-union values; pairs well with printfn
  7. collections — generic map and set (hash tables), done 2026-10-27
  8. io — buffered reader/writer over the existing fd layer — done 2026-10-24 (λlib/bufio.lora)
  9. log — levels + UTC timestamps, done 2026-10-27
  10. regex — linear-time Pike VM with captures, done 2026-10-27
  11. process and signal — starting programs, their pipes, waiting for them, and watching, ignoring and sending signals; done on macOS 2026-11-24, with running as another user, controlling terminals, the foreground, pseudo-terminals, and ending a scope on a signal. Their Linux runtime is still to do.
  12. Argument parsing (flag), done 2026-11-24, with time durations and strconv's integers in any base.
  13. The rest of fs (names, temporary files, walking, globs, copying, locks, atomic writes, removing trees) and of path (clean, abs, rel, matching), done 2026-11-24.
  14. time: instants, zones, layouts, calendar arithmetic, and timers in coro, done 2026-11-24.
  15. math, with bits and rand, done 2026-11-24; big (arbitrary-precision integers, rationals and floats) and cmplx, done 2026-11-24.
  16. crypto: SHA-3, SHAKE, cSHAKE, SHA-512/224 and /256, BLAKE2, AES decryption and AES-192, CBC, CTR, CFB, OFB, GCM with any nonce or tag, DES and triple DES, and constant-time helpers done 2026-11-24; Ed25519 (with ctx and ph), P-521 (in x509 and tls too), ECDSA in DER and EC keys from bytes, RSA key generation, OAEP and PKCS #1 v1.5 encryption and CRT done the same day; ML-KEM (512, 768, 1024), Argon2, scrypt, bcrypt, XChaCha20-Poly1305 and NaCl's boxes done the same day; DSA and RC4, and Montgomery multiplication in the runtime's assembly (RSA keys 20 times as fast to make, signatures 35 times), done the same day.
  17. tar and zip: archives, read and written, done 2026-11-24.
  18. kv: a key-value store, kept in memory or on disk, served over RESP and sharded across servers, done 2026-11-25.

Suggested order

  1. Stdlib batch: math, strings additions, sort, hash, utf8 (+json) — pure stdlib, done 2026-10-24.
  2. Generics (with cross-module templates, explicit arguments, constraints), lambdas and closures, interfaces, string interpolation, optionals, macros, comptime, reflection, coroutines and threads, and the log, regex and unicode modules — done 2026-10-27.
  3. Bitstructs + vectors — new compiler features (NOT ports: verified absent from upstream lorac master). Bitstructs done 2026-11-08; vectors deferred.
  4. Self-hosting: rewrite the compiler in Lora; the stdlib migration to first-class Lora syntax happens here (see the stage plan in docs/tooling.md and the goals in memory).

Skipped by decision: operator overloading, @deprecated/@nodoc.

Everything added to the language follows the stage-2 rule: any grammar-level break ships as one batched migration that also ports the stdlib.
